# J视频-对口型数字人

本文档收录 `comfyui-workflow/J视频-对口型数字人/` 目录下按 Windows 文件名自然排序的全部 15 个工作流。说明依据实际节点、上传输入和内置示例提示词整理，并按数字人对口型、音频驱动、原生音画生成、人物替换、视频编辑及辅助工具区分。

## J01-对口型-LTX2.3数字人GGUF版

**工作流类型：** 单图音频驱动数字人对口型工作流（LTX 2.3 GGUF）。

**主要用途：** 使用人物图和语音或歌曲生成说话、唱歌数字人视频；GGUF 主模型侧重降低主模型显存占用。

**能做到的效果：**
- 让静态人物按输入音频开口说话或唱歌。
- 按音频时长自动计算视频帧数。
- 以提示词控制表情、手势、身体动作和运镜。
- 用 Qwen3-VL 分析参考图并辅助扩写 LTX 提示词。
- 分离人声与伴奏后提取适合驱动的声音。
- 通过两遍采样和二倍空间放大改善清晰度。

**主要输入：** 一张人物参考图、一段语音或歌曲、表演与镜头提示词，以及尺寸、帧率、种子等参数。

**核心模型与技术：** LTX 2.3 22B Dev Q4_K_M GGUF、LTX 2.3 Distilled LoRA、Gemma 3 12B、Qwen3-VL 8B GGUF、MelBand RoFormer、LTX 音视频 VAE、Spatial Upscaler、双遍采样。

## J02-对口型-LTX2.3数字人标准版

**工作流类型：** 单图音频驱动数字人对口型工作流（LTX 2.3 标准权重）。

**主要用途：** 用人物图和语音或歌曲生成口播、演唱视频，采用 FP8 标准主模型而非 GGUF。

**能做到的效果：**
- 让单张人物图随语音或歌曲自然开口。
- 根据音频时长建立对应的音视频潜空间。
- 用提示词描述演唱、表情、动作和镜头焦点。
- 使用 Qwen3.5 多模态模型分析图片并扩写提示词。
- 分离人声与伴奏，保留适合驱动的声音条件。
- 通过两阶段采样和空间放大输出更清晰画面。

**主要输入：** 一张人物参考图、一段语音或歌曲、人物表演提示词，以及输出尺寸、帧率和种子。

**核心模型与技术：** LTX 2.3 22B Dev FP8、LTX 2.3 Distilled LoRA、Gemma 3 12B、Qwen3.5 27B GGUF、MelBand RoFormer、LTX 音视频 VAE、Spatial Upscaler、双遍采样。

## J03-对口型-InfiniteTalk官方流长视频无衰减

**工作流类型：** 单图长时音频驱动数字人对口型工作流。

**主要用途：** 用人物图和较长语音或歌曲分段生成连续数字人视频，适合长口播或持续演唱。

**能做到的效果：**
- 以单张人物图和音频生成说话或唱歌画面。
- 用中文 Wav2Vec2 语音特征驱动口型。
- 按设置的帧段连续进行多段采样。
- 通过前段状态衔接后段，保持动作和画面连续。
- 用提示词加入演唱状态或环绕运镜等表现。
- 合并生成片段并配回裁剪后的原音频。

**主要输入：** 人物参考图、音频、动作与运镜提示词、输出尺寸、每段帧数及种子；流程中另有用于段间衔接的图像输入节点。

**核心模型与技术：** Wan 2.1 InfiniteTalk Single、Wan 2.1 SkyReels V3 A2V、Wav2Vec2 Chinese Base、CLIP Vision H、UMT5-XXL、LightX2V I2V LoRA、连续分段采样。

## J04-对口型-InfiniteTalk单人图像驱动

**工作流类型：** 单图音频驱动数字人对口型工作流。

**主要用途：** 将一张人物图与一段语音或歌曲合成为单人说话、演唱视频；示例提示词为“男人对着镜头说话”。

**能做到的效果：**
- 由静态人物图生成单人对口型视频。
- 自动按音频时长换算总帧数。
- 分离音频中的人声并用于语音特征提取。
- 用提示词控制说话、唱歌及人物动作。
- 保留原始画幅并按最长边统一处理尺寸。
- 将裁剪后的原音频封装回输出视频。

**主要输入：** 一张人物图、一段音频、正负提示词、音频裁剪区间、目标最长边和种子。

**核心模型与技术：** Wan 2.1 I2V 14B、InfiniteTalk Single、Chinese Wav2Vec2、MultiTalkWav2VecEmbeds、CLIP Vision H、Wan Video VAE、LightX2V/Fun/Pusa LoRA。

## J05-对口型-InfiniteTalk单人视频驱动

**工作流类型：** 视频保形音频驱动数字人对口型工作流。

**主要用途：** 以现有单人视频作为画面与动作条件，使用新音频重新驱动人物口型；示例描述为闭眼深情唱歌。

**能做到的效果：**
- 在输入视频动作基础上生成新的音频驱动表演。
- 读取原视频画幅和帧率作为输出条件。
- 按新音频时长计算生成帧数。
- 提取人声和 Wav2Vec2 特征驱动口型。
- 将视频帧编码为潜空间，保留更多原始构图信息。
- 输出时合成裁剪后的新音频。

**主要输入：** 一段单人参考视频、一段新语音或歌曲、表演提示词、音频裁剪区间、处理尺寸和种子。

**核心模型与技术：** Wan 2.1 I2V 14B、InfiniteTalk Single、Chinese Wav2Vec2、WanVideoEncode、CLIP Vision H、Wan Video VAE、LightX2V/Fun/Pusa LoRA。

## J06-对口型-InfiniteTalk双人图像驱动

**工作流类型：** 双人分区音频驱动对话对口型工作流。

**主要用途：** 对一张双人合照中的左右人物分别施加音频条件，生成双人轮流说话或对唱画面。

**能做到的效果：**
- 分别使用左侧人物音频和右侧人物音频驱动口型。
- 使用完整双人对话音频确定总时长并用于最终合成。
- 通过人脸检测和 SAM3.1 建立两个人物的分区遮罩。
- 用 InfiniteTalk Multi 将不同音频绑定到对应人物区域。
- 自动按完整音频时长计算帧数。
- 保持双人在同一构图内完成对话或演唱。

**主要输入：** 一张双人图片、左侧人物独立音频、右侧人物独立音频、完整对话音频，以及尺寸、音频区间和种子。

**核心模型与技术：** InfiniteTalk Multi、Wan 2.1 I2V 14B、Chinese Wav2Vec2、MultiTalkWav2VecEmbeds、SAM 3.1、YOLOv8 Face、CLIP Vision H、Wan Video VAE。

## J07-对口型-高动态音画视频口型一条龙

**工作流类型：** 台词/音频生成加高动态对口型一体化工作流。

**主要用途：** 从台词合成语音，或直接使用自定义音频，再以单图或首尾帧生成带口型、表演和镜头运动的短视频。

**能做到的效果：**
- 支持单张图和首尾帧两种画面输入方式。
- 可用 Qwen3-TTS 根据台词和声线生成对白音频。
- 也可跳过语音合成，直接上传自定义音频。
- 用 Qwen3-VQA 根据图片、台词扩写五秒动态提示词。
- 通过 InfiniteTalk 将语音特征用于人物口型。
- 以 Wan 2.2 Remix 高低噪模型完成高动态视频采样。

**主要输入：** 单图或首尾帧图片、台词文本与参考声线，或自定义音频；另含动作描述、尺寸和采样参数。

**核心模型与技术：** Wan 2.2 Remix I2V 高低噪模型、InfiniteTalk Single、Wav2Vec2 Chinese、Qwen3-TTS 1.7B、Qwen3-VQA、CLIP Vision、MelBand RoFormer、Fun InP LoRA。

**视频教程：** https://www.bilibili.com/video/BV1zq6sBvEC7/?spm_id_from=333.40164.top_right_bar_window_dynamic.content.click&vd_source=30b3fed7dfde8379c4ba83f85224199b

## J08-LTX2.3数字人说话唱歌对口型-优化升级kj版

**工作流类型：** 单图音频驱动数字人对口型工作流。

**主要用途：** 使用人物图和上传音频生成 LTX 2.3 说话或唱歌视频，示例提示词为人物面对镜头说话并配合简单动作。

**能做到的效果：**

- 分离人声并编码为 LTX 音频潜空间。
- 通过 NAG 和高级采样控制生成质量。
- 使用空间放大模型提高输出分辨率。

**主要输入：** 一张人物图、一段语音或歌曲、表演提示词、画幅与尺寸、时长和采样参数。

**核心模型与技术：** LTX 2.3 Distilled FP8、LTX 2.3 Distilled LoRA、Gemma 3 12B、MelBand RoFormer、LTX 音视频 VAE、LTX ImgToVideo KJ、Spatial Upscaler、NAG。

## J09-LTX2.3双人对话-图生视频音画同步-KJ优化版

**工作流类型：** 双人原生音画图生视频工作流。

**主要用途：** 从双人图片和带角色台词、动作的提示词生成两人对话视频，声音由 LTX 音频潜空间同步生成，并非上传音频后做口型迁移。

**能做到的效果：**
- 将双人静态图转成带对白的动态场景。
- 在提示词中分别指定左右角色的台词和互动。
- 同步生成画面与音频潜变量。
- 用 Qwen3.5 视觉语言模型分析图片并扩写镜头描述。
- 通过 Licon LoRA 加强人物动作和互动表现。
- 保留对话文字、人物动作和镜头调度的统一描述。

**主要输入：** 一张双人场景图、两名角色的台词与动作提示、视频尺寸、时长和采样参数。

**核心模型与技术：** LTX 2.3 Distilled FP8、LTX 音视频 VAE、LTX ImgToVideo KJ、Licon VBVR I2V LoRA、Qwen3.5 9B GGUF、多模态图像描述、音视频联合潜空间采样。

## J11-提示词参数预处理

**工作流类型：** 电商数字人提示词预处理辅助工作流。

**主要用途：** 在正式生成前分析人物持商品图片，并结合商品文案生成结构化画面描述和 LTX 提示词参数；本文件本身不负责生成视频。

**能做到的效果：**
- 识别人物年龄、外观、妆容、服饰和姿态。
- 识别手持商品的外形、材质、颜色和位置。
- 将商品文案与参考图信息合并。
- 输出可供主工作流使用的英文图像描述。
- 预先整理数字人口播所需的提示词内容。

**主要输入：** 一张人物或人物持商品图片、商品介绍文本，以及补充的动作和口播要求。

**核心模型与技术：** Qwen3.6 35B A3B GGUF、多模态投影模型、llama.cpp 图像理解、文本参数预处理。

## J12电商数字人物替换-姿态迁移-背景替换v3版

**工作流类型：** 视频人物替换、背景替换与动作迁移工作流。

**主要用途：** 对电商或人物视频进行角色替换、背景替换，或把驱动视频动作迁移到参考人物图；它不是对口型流程。

**能做到的效果：**
- 用参考人物替换视频中的原人物。
- 将驱动视频动作迁移到静态人物图。
- 使用参考场景替换或重建视频背景。
- 以 SAM3.1、SDPose 和 ViTPose 提取人物遮罩及姿态。
- 通过 Uni3C 控制人物结构和镜头运动。
- 合并生成主体、背景和原视频音频。

**主要输入：** 驱动/原始视频、人物参考图、背景参考图，以及替换模式、提示词、遮罩扩展和采样参数。

**核心模型与技术：** Wan 2.2 Animate 14B、Wan Uni3C ControlNet、SAM 3.1、SDPose WholeBody、ViTPose、YOLOv10、RT-DETR、CLIP Vision、LightX2V/Fun/Pusa/Relight LoRA。

## J13-小珠光90秒全自动版-单人InfiniteTalk

**工作流类型：** 单图长时音频驱动数字人对口型工作流。

**主要用途：** 将一张人物图和较长音频自动拆分为多段生成，再拼接为最长约 90 秒的单人说话或演唱视频。

**能做到的效果：**
- 按音频时长自动计算总帧数。
- 将长音频分段并提取 Wav2Vec2 特征。
- 使用六段生成链路依次处理较长内容。
- 从提示词行中为各段选择人物动作描述。
- 保持单个人物在连续片段中的构图和身份。
- 合并各段画面并配回处理后的完整音频。

**主要输入：** 一张单人参考图、一段长音频、分段动作提示词列表，以及帧率、分段长度和采样参数。

**核心模型与技术：** Wan 2.1 I2V 720p LightX2V、InfiniteTalk Single、Wav2Vec2 Chinese、CLIP Vision H、MelBand RoFormer、分段采样与自动拼接。

## J14-Bernini-电商换产品视频编辑

**工作流类型：** Bernini 参考图视频编辑工作流。

**主要用途：** 依据参考图片编辑输入视频中的人物或商品相关主体；内置示例明确要求把视频中的女性替换为图片中的女性并保持参考外观。

**能做到的效果：**
- 使用参考图片指定视频中的替换主体。
- 按文字指令执行人物或商品相关视频编辑。
- 保留输入视频的时序、镜头和背景结构。
- 读取原视频帧率和尺寸用于生成。
- 采用高低噪两阶段模型完成编辑采样。
- 将编辑结果与视频音频封装输出。

**主要输入：** 一段待编辑视频、一张人物或商品参考图、明确的替换/编辑提示词，以及采样和输出参数。

**核心模型与技术：** Wan 2.2 Bernini High/Low FP8、BerniniConditioning、UMT5-XXL、Wan 2.1 VAE、LightX2V 四步高低噪 LoRA、双阶段采样。
