# F图像-FireRed图像编辑

本文档收录 `comfyui-workflow/F图像-FireRed图像编辑/` 目录下的全部工作流。说明根据工作流名称、实际节点、上传输入及内部示例提示词整理。


## F01-FireRed-Image-Edit-1

**工作流类型：** 多图参考图像编辑工作流

**主要用途：** 基于 FireRed Image Edit 的自然语言改图流程，可上传一张主图和最多两张辅助参考图，通过中文指令修改季节、场景、道具、妆容或人物状态。支持快速与标准两档采样，适合多参考图融合和语义编辑。

**能做到的效果：**
- 使用一至三张图片进行联合参考编辑。
- 根据中文指令修改季节、环境、物品和人物状态。
- 可开启化妆 LoRA 调整人物妆容。
- 在 Lightning 快速采样和标准高步数采样间切换。
- 通过多图参考保持目标内容和主体特征。

**主要输入：** 一张待编辑主图、最多两张辅助参考图、中文编辑提示词和随机种子。

**核心模型与技术：** FireRed Image Edit 1.0、Qwen2.5-VL 7B、Lightning LoRA、Makeup LoRA、AuraFlow 采样。

## F02-图像-FireRed人物换背景

**工作流类型：** 多图参考图像编辑工作流

**主要用途：** 基于 FireRed Image Edit 1.1 的人物换背景与光照融合流程。图一提供需要保留的人像，图二提供目标场景，第三张图片可作为额外参考；内置指令会将人物放入新场景，并根据场景光源方向自动调整融合效果。

**能做到的效果：**
- 保留图一人物并替换为图二中的背景场景。
- 根据目标场景的光源方向调整人物受光。
- 使用第三张图片补充可选人物、物体或风格参考。
- 在原图长边限制和自定义输出尺寸间切换。
- 自动缩放多张输入图并统一到编辑尺寸。
- 预览原图与换背景结果的对比效果。

**主要输入：** 必选人物主图、目标背景图、可选第三张参考图、中文编辑指令、尺寸模式和随机种子。

**核心模型与技术：** FireRed Image Edit 1.1 FP8 Mixed、Qwen2.5-VL 7B、Qwen Image Lightning 8 步 LoRA、AuraFlow 采样、多图条件编码。
