# K视频-人物替换

本文档收录 `comfyui-workflow/K视频-人物替换/` 目录下按 Windows 文件名自然排序的全部 12 个工作流。说明依据实际节点、上传输入和内置示例提示词整理，并区分换头换装、人物/背景替换、影视二创、视频编辑及动作迁移。

## K01-换装-Wan换头换服装换背景娱乐流

**工作流类型：** 换头、换装、换背景与整人替换综合视频编辑工作流。

**主要用途：** 在同一文件中提供四套 Wan Animate 分支，分别处理单人换头、换服装、换背景和完整人物迁移。

**能做到的效果：**
- 只替换视频人物头部并保留身体动作。
- 根据参考图改变动态人物服装。
- 将原视频背景替换为参考场景。
- 把驱动视频中的完整人物替换为新角色。
- 用 SAM3 分离人物、背景和指定编辑部位。
- 提取姿态并在输出中合成原视频音频。

**主要输入：** 根据所选分支上传驱动视频，以及脸部、服装、背景或完整人物参考图；部分分支还需设置 SAM3 目标和提示词。

**核心模型与技术：** Wan 2.2 Animate 14B FP8、SAM3、DWPose/姿态关键点、CLIP Vision H、WanVideoAnimateEmbeds、LightX2V、Relight、Pusa 与 Fun InP LoRA、遮罩合成。

## K02-换装-Wan2.2不挑图换装流

**工作流类型：** 单图定向换装工作流。

**主要用途：** 通过手工涂抹服装区域完成静态人物换装，适合自动服装识别不稳定或服饰边界复杂的图片。

**能做到的效果：**
- 手工精确标记需要替换的服装区域。
- 使用 Florence2 自动描述人物图内容。
- 提取 OpenPose 姿态以保持身体结构。
- 用 CLIP Vision 保留人物整体视觉条件。
- 对遮罩填洞、分块和边缘进行处理。
- 使用 Wan Animate 根据遮罩生成换装结果。

**主要输入：** 一张人物原图、同一图片的手工涂抹遮罩版本，以及换装提示词、尺寸和种子。

**核心模型与技术：** Wan 2.2 Animate 14B FP8、Florence-2 PromptGen v2、OpenPose、CLIP Vision H、BlockifyMask、Mask Fill Holes、Relight/Lightning/FastWan/Pusa/Fun InP LoRA。

## K03-影视二创-Wan影视二创

**工作流类型：** 单角色影视人物替换与动作复刻工作流。

**主要用途：** 使用新角色参考图替换影视视频中的原人物，并延续原片动作、镜头和时序。

**能做到的效果：**
- 将影视片段中的原角色替换为参考图人物。
- 提取全身姿态和面部关键点保持原表演。
- 在指定帧手动打点并生成整段人物遮罩。
- 使用 SeC 视频分割跟踪目标人物。
- 保留原视频镜头节奏并合成原音频。
- 通过多组加速、补光和质量 LoRA 控制生成。

**主要输入：** 一张新角色参考图、一段原影视视频、遮罩跟踪目标点、参考帧、提示词、帧率和种子。

**核心模型与技术：** Wan 2.2 Animate 14B FP8、SDPose OOD、ViTPose、YOLOv10、SeC-4B Video Segmentation、CLIP Vision H、WanVideoAnimateEmbeds、LightX2V/Relight/Pusa/Fun InP LoRA。

## K04-影视二创-WorkFisher单人版

**工作流类型：** 单人影视角色替换与动作迁移工作流。

**主要用途：** 用一张新角色图替换原视频中的单个人物，以原视频姿态和时序驱动新角色。

**能做到的效果：**
- 提取原视频中单人的全身与面部姿态。
- 将参考图人物外观迁移到原角色位置。
- 保留原视频动作、构图和镜头节奏。
- 通过 YOLO 与 ViTPose 定位人物并生成姿态条件。
- 使用 RIFE 对处理后的帧序列进行插帧。
- 合并生成画面与原视频音频。

**主要输入：** 一段单人驱动视频、一张新角色参考图、替换/动作提示词、帧窗口、循环次数、尺寸和种子。

**核心模型与技术：** Wan 2.2 Animate 14B FP8、SDPose OOD、ViTPose、YOLOv10/YOLO11、CLIP Vision H、RIFE 4.7、WanVideoAnimateEmbeds、Relight/Lightning/FastWan/Pusa/Fun InP LoRA。

## K05-影视二创-WorkFisher多人版

**工作流类型：** 多人场景影视角色替换与动作迁移工作流。

**主要用途：** 面向画面中包含多个人物的影视片段，检测并保留多人姿态关系，再对指定角色进行参考图替换。

**能做到的效果：**
- 检测视频中的多个人体和对应姿态。
- 在多人互动场景中维持原始位置关系。
- 将参考角色外观应用到目标人物。
- 保留动作、镜头运动和原片时序。
- 用分段窗口处理较长的帧序列。
- 通过 RIFE 插帧并合成原视频音频。

**主要输入：** 一段多人影视视频、一张目标角色参考图、目标人物选择与提示词、帧窗口、循环次数、尺寸和种子。

**核心模型与技术：** Wan 2.2 Animate 14B FP8、SDPose OOD、ViTPose、YOLOv10/YOLO11、CLIP Vision H、RIFE 4.7、多人物姿态检测、Relight/Lightning/FastWan/Pusa/Fun InP LoRA。

## K06-Wan-Animate最强视频人物替换-动作迁移

**工作流类型：** 单人视频人物替换与动作迁移工作流。

**主要用途：** 以参考人物图重建驱动视频中的人物，支持保留原背景的人物替换，也可仅使用动作条件生成新场景。

**能做到的效果：**
- 将驱动视频人物替换为参考图角色。
- 把原视频全身与面部动作迁移给新角色。
- 通过 SeC 分割和手动点选建立人物遮罩。
- 可按节点连接方式选择保留或不使用原背景。
- 以 RIFE 插帧改善输出帧率和动作连续性。
- 合成处理后的画面与原视频音频。

**主要输入：** 一张新角色参考图、一段驱动视频、目标点或遮罩设置、提示词、帧窗口、输出尺寸和种子。

**核心模型与技术：** Wan 2.2 Animate 14B FP8、SDPose OOD、ViTPose、YOLOv10、SeC-4B Video Segmentation、CLIP Vision H、RIFE 4.7、Relight/Lightning/FastWan/Pusa/Fun InP LoRA。

**视频教程：** https://www.bilibili.com/video/BV15LS1BCEh5/?vd_source=acbc4fd0610ec0529cc3c194ed00e4b0

## K07-人物替换-背景替换-Wan2.2 Animate-姿态对齐-Sam3.1-SDPose最强工作流-肥猴V5

**工作流类型：** 人物替换、背景替换与姿态对齐综合工作流。

**主要用途：** 将参考人物和参考背景组合到驱动视频中，并通过自动或手动姿态对齐控制角色动作。

**能做到的效果：**
- 用参考人物替换原视频主体。
- 使用参考场景重建或替换视频背景。
- 使用 ViTPose + YOLOv10m 提取姿态与人脸条件，并由 YOLO11x 检测人物边界框以辅助姿态比例对齐。
- 支持手动编辑 Anchor 帧和姿态关键点。
- 通过 SAM3.1 跟踪人物并扩展融合遮罩。
- 生成主体与背景过渡片段并合成音频。

**主要输入：** 驱动视频、人物参考图、背景图或背景视频，可选 Anchor 帧/姿态视频，以及替换模式、遮罩和采样参数。

**核心模型与技术：** Wan 2.2 Animate 14B、WanAnimatePlus、Sam3.1 Multiplex、SDPose WholeBody、ViTPose WholeBody + YOLOv10m 姿态/人脸预处理、YOLO11x 人物边界框检测、BodyRatioMapper 姿态比例映射、CLIP Vision H、LightX2V I2V LoRA、Wan 2.1 Fun InP、视频遮罩合成。

## K08-Wan2.2-Bernini人物替换-动作迁移-多图参考-视频编辑工作流v1版

**工作流类型：** Bernini 多图参考视频编辑与动作迁移工作流。

**主要用途：** 结合参考视频和最多十张参考图编辑人物、服装或场景，并让参考角色沿用驱动视频动作。

**能做到的效果：**
- 使用单张或多张图片提供角色与场景参考。
- 以参考视频提供动作、镜头和时序。
- 在提示词中指定不同参考图对应的人物或环境。
- 支持人物替换、多人组合和参考式视频编辑。
- 读取原视频尺寸、帧率并按上下文窗口处理。
- 采用 Bernini 高低噪模型进行两阶段生成。

**主要输入：** 一段参考/驱动视频、1 至 10 张人物或场景参考图、引用各图片的编辑提示词，以及上下文、采样和输出参数。

**核心模型与技术：** Wan 2.2 Bernini High/Low FP8、WanAnimatePlus Bernini、UMT5-XXL、Wan 2.1 VAE、多图参考条件、高低噪 LightX2V 四步 LoRA、上下文分段采样。

## K09-Bernini-视频换人-角色替换

**工作流类型：** Bernini 单参考图视频换人工作流。

**主要用途：** 用一张新人物图替换输入视频中的原角色，适合不需要额外姿态检测链路的参考式视频编辑。

**能做到的效果：**
- 将视频原角色替换为参考图中的新人物。
- 使用参考图约束新角色身份和外观。
- 沿用原视频动作、镜头与场景时序。
- 根据原视频信息设置生成长度和帧率。
- 使用高低噪 Bernini 模型分阶段采样。
- 输出带原视频音频的替换结果。

**主要输入：** 一段待换人视频、一张新人物参考图、角色替换提示词，以及上下文、采样和输出参数。

**核心模型与技术：** Wan 2.2 Bernini High/Low FP8、WanAnimatePlus Bernini、UMT5-XXL、Wan 2.1 VAE、高低噪 LightX2V 四步 LoRA、参考式视频编辑。

## K10-豹豹喵呜-SCAIL-V2动作迁移-角色替换二合一工作流

**工作流类型：** SCAIL 2 动作迁移与角色替换二合一工作流。

**主要用途：** 用参考人物图和驱动视频生成角色动作复刻，可通过 SAM3.1 视频跟踪遮罩控制是否执行角色替换。

**能做到的效果：**
- 将驱动视频动作迁移到参考图人物。
- 按开关选择动作迁移或带遮罩的角色替换。
- 用 SAM3.1 在视频中跟踪目标人物。
- 将跟踪遮罩编码为 SCAIL 2 彩色控制条件。
- 通过 for 循环分段处理视频帧。
- 合并生成画面与原视频音频。

**主要输入：** 一张角色参考图、一段驱动视频、SAM3.1 跟踪目标、模式开关、动作提示词和采样参数。

**核心模型与技术：** Wan 2.1 SCAIL 2 NVFP4、WanSCAILToVideo、SCAIL2ColoredMask、SAM 3.1 VideoTrack、CLIP Vision ViT-H、UMT5-XXL、LightX2V LoRA、循环分段采样。

**视频教程：** https://www.bilibili.com/video/BV1NnEq6FED9

## K11-SCAIL2动作迁移-角色替换-支持长视频-像素幻想Lab

**工作流类型：** SCAIL 2 长视频动作迁移与角色替换工作流。

**主要用途：** 以参考角色图和较长驱动视频进行分段动作迁移，并可选择使用人物跟踪遮罩完成角色替换。

**能做到的效果：**
- 将长视频动作分段迁移到新角色。
- 通过开关选择是否执行角色替换。
- 使用 SAM3.1 持续跟踪驱动视频人物。
- 将人物遮罩转换为 SCAIL 2 彩色控制图。
- 按首帧数、帧步和最长边设置处理规模。
- 拼接各段并合成原视频音频。

**主要输入：** 一段驱动视频、一张角色参考图、角色替换开关、首帧/帧步/最长边参数、提示词和采样参数。

**核心模型与技术：** Wan 2.1 SCAIL 2 NVFP4、WanAnimatePlus SCAIL 2 Embeds、SAM 3.1 VideoTrack、SCAIL2ColoredMask、CLIP Vision H、UMT5-XXL、LightX2V LoRA、上下文分段。

**视频教程：** https://www.bilibili.com/video/BV1CqE16JERa

## K13-AI代码侠土豆-SCAIL2-全自动循环流

**工作流类型：** SCAIL 2 全自动循环动作迁移工作流。

**主要用途：** 根据驱动视频总帧数自动计算循环次数，连续生成并拼接参考角色的动作迁移视频。

**能做到的效果：**
- 自动读取驱动视频帧数并计算循环次数。
- 以参考人物图提供新角色外观。
- 用 SAM3.1 跟踪原视频目标人物。
- 将跟踪结果编码为 SCAIL 2 彩色遮罩条件。
- 首段生成后按固定有效帧数继续循环采样。
- 自动拼接各段并合成原视频音频。

**主要输入：** 一段驱动视频、一张人物参考图、SAM3.1 跟踪目标、动作提示词、尺寸和采样参数。

**核心模型与技术：** Wan 2.1 SCAIL 2 NVFP4、SCAIL 2 DPO LoRA、LightX2V I2V LoRA、SAM 3.1 VideoTrack、SCAIL2ColoredMask、CLIP Vision ViT-H、自动帧数计算与循环采样。
