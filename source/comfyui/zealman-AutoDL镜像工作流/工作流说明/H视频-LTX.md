# H视频-LTX

本文档收录 `comfyui-workflow/H视频-LTX/` 目录下按 Windows 文件名自然排序的全部 32 个工作流。说明根据实际节点、上传输入及内部示例提示词整理。


## H14-LTX2.3-导演台2.0

**工作流类型：** 综合工作流

**主要用途：** 基于 LTX 2.3 导演台制作多段连续音视频。时间轴示例使用六张分镜图、六段动作与台词以及一条完整音频，编排人物轮流说话和镜头切换，适合短剧、多人对话、广告和剧情预演。

**能做到的效果：**
- 在时间轴中编排六段分镜，并分别设置参考图、持续帧数、动作、运镜和台词。
- 支持仰拍推进、向右平移、俯视和半身特写等镜头语言。
- 导入整段音频并与六段画面共同生成。
- 使用 Licon MSR 组合人物与背景等多图参考。
- 通过 Transition LoRA 和导演引导控制分镜衔接。
- 使用 NAG 负向引导抑制字幕和画面文字。

**主要输入：** 多张分镜参考图、可选人物与背景参考图、分段提示词、全局提示词、整段音频、各段长度和输出尺寸。

**核心模型与技术：** LTX 2.3 22B Distilled FP8、Gemma 3 12B、YusuLTXDirector/YusuLTXDirectorGuide、Licon MSR、Transition LoRA、LTX 音视频联合采样、NAG。

**视频教程：** [哔哩哔哩](https://www.bilibili.com/video/BV1R27H6wExo)

## H15-文图生视频-LTX2.3二合一GGUF版

**工作流类型：** 综合工作流

**主要用途：** 将 LTX 2.3 文生视频和图生视频整合在同一流程中，并使用 GGUF 主模型降低显存需求。可直接输入故事情节生成视频，也可上传一张参考图作为首帧，还能用本地视觉语言模型反推并扩写 LTX 提示词。

**能做到的效果：**
- 在文生视频与单图图生视频模式间切换。
- 根据中文故事情节生成包含动作、运镜和对话的英文提示词。
- 使用 Qwen3-VL 分析参考图并补充动态描述。
- 保留输入对话原文并生成对应人物动作和声音。
- 通过两阶段采样和潜空间二倍放大提升清晰度。
- 使用 NAG 抑制字幕、水印和画面文字。

**主要输入：** 文生模式输入故事情节；图生模式上传一张参考图片并输入动作或剧情描述；同时设置宽高、秒数、帧率和随机种子。

**核心模型与技术：** LTX 2.3 22B Dev Q4_K_M GGUF、LTX 2.3 Distilled LoRA、Gemma 3 12B、Qwen3-VL 8B GGUF、LTX 音视频 VAE、Spatial Upscaler、双遍采样、NAG。
