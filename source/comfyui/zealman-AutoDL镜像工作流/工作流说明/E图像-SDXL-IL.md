# E图像-SDXL-IL

本文档收录 `comfyui-workflow/E图像-SDXL-IL/` 目录下的全部工作流。说明根据工作流名称、实际节点、上传输入及内部示例提示词整理。


## E01-文生图-Illustrious

**工作流类型：** 二次元文生图与高清放大工作流

**主要用途：** 基于 Illustrious/NoobAI 二次元模型和多组 LoRA 生成精细角色立绘。工作流支持画师标签、角色特征、厚涂光影和分段提示词控制，出图后再通过 4×Remacri 放大，适合动漫角色、游戏立绘和高精度插画。

**能做到的效果：**
- 生成二次元人物、动漫插画和竖版角色立绘。
- 叠加多组 LoRA 控制画风、光影和角色特征。
- 使用正负向提示词改善手部和整体画质。
- 支持画师标签及 BREAK 分段提示结构。
- 使用 4×Remacri 对成图进行高清放大。

**主要输入：** 正向提示词、负向提示词、LoRA 触发词、画面尺寸和随机种子。

**核心模型与技术：** SmoothMix Illustrious2 NoobAI V4、多组二次元 LoRA、CLIP 层控制、4×Remacri。

## E02-文生图-SDXL-SmoothWorkflow

**工作流类型：** 二次元文生图与人脸精修综合工作流

**主要用途：** 围绕 SmoothMix Illustrious2/NoobAI 搭建的完整 SDXL 文生图流程，将提示词编码、尺寸、采样、HiRes Fix 和 ADetailer 分区配置。适合生成二次元人物、精细立绘和需要高清修复的人像插画。

**能做到的效果：**
- 使用正负向提示词生成二次元人物和插画。
- 自定义画面尺寸、种子、CFG、采样器和调度器。
- 通过 4×Remacri HiRes Fix 放大并补充细节。
- 使用 YOLO 自动检测画面中的人脸区域。
- 结合 SAM 与 FaceDetailer 对脸部进行二次精修。
- 支持通配提示词和高级 CLIP 文本权重控制。

**主要输入：** 正向与负向提示词、画面尺寸、采样参数、随机种子、高清修复和人脸精修参数，无需上传图片。

**核心模型与技术：** SmoothMix Illustrious2 NoobAI V4、SDXL VAE、4×Remacri HiRes Fix、FaceDetailer、YOLOv8 Face、SAM ViT-B。

## E03-文生图-二次元漫画模型

**工作流类型：** 文生图与图片反推综合工作流

**主要用途：** 面向二次元漫画角色的 SDXL/Illustrious 生成流程，内置多套模型选择说明和人物标签示例。既可直接输入标签生成插画，也可上传参考图片用 WD14 Tagger 反推标签，再经过二次采样与两倍放大提升成图质量。

**能做到的效果：**
- 使用 Danbooru 风格标签生成二次元人物和漫画插画。
- 按示例切换角色外观、服装、姿势和画面构图。
- 上传参考图并自动反推可复用的图像标签。
- 将反推标签拼接到生成提示词中辅助复刻画面特征。
- 通过第二次采样改善放大后的细节和稳定性。
- 使用 OmniSR 2× 对成图进行高清放大。

**主要输入：** 正向与负向标签提示词、画面尺寸和随机种子；使用反推功能时额外上传一张参考图片。

**核心模型与技术：** IL-Gembyte 20 Emerald、Illustrious/SDXL、WD14 Tagger、二次采样、OmniSR 2× 放大、提示词拼接。
