## Q1-全能图像Pro剧情分镜设计

**工作流类型：** 多图参考图像生成与剧情分镜综合工作流

**主要用途：** 通过 Gemini 图像 API 制作剧情分镜。首图模式可上传多张人物设定图并生成四宫格电影分镜，剧情延展模式则根据已有四宫格和新脚本继续生成下一幕，适合短剧策划、广告脚本和连续故事板制作。

**能做到的效果：**
- 使用一至四张人物设定图生成四宫格分镜。
- 按剧情提示生成特写、双人和全景等不同镜头。
- 根据已有四宫格继续延展下一段剧情。
- 保持人物、环境、色调和电影质感的一致性。
- 可使用 SeedVR2 将分镜图片放大至 4K。

**主要输入：** 人物参考图、API Key、剧情或分镜提示词；延展模式还需已有分镜图。

**核心模型与技术：** Gemini 3 Pro Image Preview API、GeeknowGeminiImageI2I、SeedVR2、Comfyui-MyApi。
