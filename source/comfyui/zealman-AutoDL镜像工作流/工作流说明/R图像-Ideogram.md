# R图像-Ideogram

本文档收录全部 `comfyui-workflow/R图像-Ideogram/` 目录下的工作流，按 Windows 文件名自然排序。说明根据工作流名称、实际节点、上传输入及内部示例提示词整理。


## R01-Ideogram4半自动文生图-Work-Fisher-V2

**工作流类型：** 结构化提示词文生图工作流

**主要用途：** 基于 Ideogram 4 的结构化文生图流程。用户可以在 DirectJSON Builder 中填写场景、风格、背景和元素，也可以导入完整 JSON，通过区域坐标规划物体与文字布局，适合海报、平面设计和复杂构图图片生成。

**能做到的效果：**
- 使用结构化 JSON 描述场景、风格和构图。
- 通过 bbox 控制多个物体及文字区域的位置。
- 在 Quality、Default 和 Turbo 三档采样间切换。
- 设置宽高比和百万像素级输出尺寸。
- 使用可视化 Builder 编辑元素框、背景、媒介和配色。

**主要输入：** 结构化文本提示、元素区域、宽高比、像素规格、采样预设和随机种子。

**核心模型与技术：** Ideogram 4、Qwen3-VL 8B、Flux2 VAE、Ideogram4Scheduler、DualModelGuider、DirectJSON Builder。

## R02-Ideogram4工作流带翻译节点+kjnodes区域提示词节点

**工作流类型：** 翻译辅助的区域控制文生图工作流

**主要用途：** 使用中文分别填写整体描述、画风、美学、灯光和媒介，经翻译节点转换为英文后，由 KJNodes 的 Ideogram4 Prompt Builder 组织成结构化提示词。适合制作带指定文字、物体位置和复杂版式的海报、漫画封面与平面设计。

**能做到的效果：**
- 将中文场景与风格描述分别翻译为英文提示字段。
- 在可视化区域编辑器中绘制物体和文字框。
- 保留指定文字内容并控制其位置、字体质感和版式。
- 通过宽高比与百万像素选项设置生成尺寸。
- 在 Quality、Default、Turbo 三档 Ideogram 4 采样预设间切换。
- 将区域预览、生成结果及混合对照图并排查看。

**主要输入：** 中文整体描述、背景、画风、美学、灯光、媒介、区域框与文字内容，以及宽高比、采样预设和随机种子；无需上传图片。

**核心模型与技术：** Ideogram 4、Qwen3-VL 8B、Flux2 VAE、Ideogram4PromptBuilderKJ、DeepTranslator、Ideogram4Scheduler、DualModelGuider。

## R03-image_ideogram4_t2i

**工作流类型：** 结构化提示词文生图工作流

**主要用途：** 使用 Ideogram 4 根据结构化 JSON 生成广告海报、品牌视觉和带文字版式的图片。工作流保留了一个可选的 Gemma 4 提示词生成分组，可将简短创意扩写为场景、风格、背景、文字和区域坐标完整的 JSON。

**能做到的效果：**
- 直接使用完整 JSON 控制主体、背景、风格和色板。
- 通过 bbox 安排标题、副标题、人物和产品区域。
- 生成中英文可见文字及品牌海报式版面。
- 按常用宽高比和百万像素规格设置画布。
- 选择 Quality、Default 或 Turbo 采样参数。
- 可启用 Gemma 4 将简短英文创意扩写为结构化提示词。

**主要输入：** 结构化 JSON 提示词、宽高比、像素规格、采样档位和随机种子；可选输入简短英文创意供 Gemma 4 扩写，无需上传图片。

**核心模型与技术：** Ideogram 4、Qwen3-VL 8B、可选 Gemma 4 E4B、Flux2 VAE、Ideogram4Scheduler、DualModelGuider、结构化 JSON 与 bbox 布局。

## R04-ideogram4出九宫格故事板

**工作流类型：** 九宫格故事板文生图工作流

**主要用途：** 使用 Ideogram 4 将连续镜头描述组织为一张 3×3 九宫格故事板，适合预演人物动作、场景变化和镜头顺序。

**能做到的效果：**
- 将九个镜头安排在统一的 3×3 网格中。
- 分别描述每格的主体、动作、景别和环境。
- 使用结构化提示保持固定的格数与阅读顺序。
- 在同一张图中呈现连续剧情或拍摄方案。
- 按画布宽高比和像素规格控制输出尺寸。

**主要输入：** 九个分镜的文字描述、整体风格与角色约束、画布比例、采样预设和随机种子；无需上传图片。

**核心模型与技术：** Ideogram 4、Qwen3-VL、Flux2 VAE、结构化 JSON、网格版式提示、Ideogram4Scheduler。

## R05-ideogram4出四宫格-六宫格

**工作流类型：** 四宫格与六宫格分镜文生图工作流

**主要用途：** 根据镜头文本生成四格或六格组合画面，用于短剧情节、镜头草图和多场景视觉规划。

**能做到的效果：**
- 按设置生成四宫格或六宫格组合版式。
- 为每一格指定人物、动作、场景和镜头信息。
- 使用统一风格描述协调多格画面的视觉表现。
- 通过明确的面板顺序组织连续情节。
- 设置输出宽高比、像素规格和采样档位。

**主要输入：** 四个或六个分镜描述、整体风格与版式要求、画布比例、采样预设和随机种子；无需上传图片。

**核心模型与技术：** Ideogram 4、Qwen3-VL、Flux2 VAE、结构化分镜提示、Ideogram4Scheduler、DualModelGuider。
