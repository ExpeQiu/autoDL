# Y通用制作

本文档收录全部 `comfyui-workflow/Y通用制作/` 目录下的工作流，按 Windows 文件名自然排序。说明根据工作流名称、实际节点、上传输入及内部示例提示词整理。


## Y01-图像修改千问2511

**工作流类型：** 图生图与图像编辑工作流

**主要用途：** 基于 Qwen Image Edit 2511 的单图语义编辑流程。上传一张图片并输入中文指令，即可修改人物表情、季节、场景或其他画面内容，使用 Lightning LoRA 进行四步快速采样，适合日常改图和创意调整。

**能做到的效果：**
- 根据中文自然语言指令修改单张图片。
- 调整人物表情、季节、环境和画面内容。
- 自动按最长边缩放并保持原图比例。
- 将原图作为 ReferenceLatent 参考条件。
- 使用 Lightning LoRA 快速完成编辑。

**主要输入：** 一张待编辑图片、中文编辑提示词、最长边尺寸和随机种子。

**核心模型与技术：** Qwen Image Edit 2511、Lightning 4 步 LoRA、F2P LoRA、ReferenceLatent、CFGNorm。

## Y02-图像修改克莱因

**工作流类型：** 图生图与图像编辑工作流

**主要用途：** 使用 Flux 2 Klein 对单张参考图执行中文语义修改。工作流将原图缩放并编码为参考潜空间，再根据编辑指令生成与原图同尺寸的新画面，适合表情、季节、场景和局部内容调整。

**能做到的效果：**
- 根据中文指令修改上传图片中的人物或环境。
- 调整表情、季节和场景，同时参考原图构图。
- 自动将输入图缩放至约 1MP 并读取实际宽高。
- 使用双 ReferenceLatent 构建正向与零化负向参考条件。
- 通过一致性 LoRA 加强人物与原图特征保持。

**主要输入：** 一张待编辑图片、中文编辑提示词、随机种子和可选一致性 LoRA 强度。

**核心模型与技术：** Flux 2 Klein 9B、Qwen 3 8B 文本编码器、Flux2 VAE、ReferenceLatent、Flux2Scheduler、Klein 一致性 LoRA。

## Y03-图像修改FireRed

**工作流类型：** 图生图与图像编辑工作流

**主要用途：** 基于 FireRed Image Edit 对单张图片执行中文指令编辑。可在完整质量模式与 Lightning 8 步加速模式之间切换，并自动联动步数和 CFG，适合快速修改人物表情、季节、环境及画面内容。

**能做到的效果：**
- 上传一张图片并用中文指令进行语义编辑。
- 修改人物表情、季节、背景和场景状态。
- 使用 Flux Kontext 尺寸规则预处理输入图片。
- 一键切换标准模型或 Lightning LoRA 加速路线。
- 在加速模式下自动使用 8 步、低 CFG 参数。
- 保留输入图作为正向与负向编辑条件。

**主要输入：** 一张待编辑图片、中文编辑提示词、是否启用加速 LoRA 的开关，以及随机种子。

**核心模型与技术：** FireRed Image Edit 1.0、Qwen2.5-VL 7B、Qwen Image VAE、FireRed Lightning 8 步 LoRA、TextEncodeQwenImageEditPlus、FluxKontextImageScale。

## Y04-图像生成Zimage

**工作流类型：** Z-Image 文生图工作流

**主要用途：** 使用 Z-Image 根据中文或英文提示词直接生成图片，提供基础尺寸、采样和随机种设置，适合作为通用文生图模组。

**能做到的效果：**
- 根据自然语言提示生成单张图片。
- 使用正向描述控制主体、场景和画面风格。
- 通过负向提示排除不需要的内容。
- 自定义画面宽高、采样步数和引导参数。
- 使用固定或随机种子控制结果变化。

**主要输入：** 正向提示词、负向提示词、目标宽高、采样参数和随机种子；无需上传图片。

**核心模型与技术：** Z-Image、文本编码、VAE 解码、扩散采样、基础潜空间生成。

## Y05-图像生成Qwen2512

**工作流类型：** Qwen Image 2512 文生图工作流

**主要用途：** 使用 Qwen Image 2512 根据文本描述生成图片，适合人物、场景和带明确构图要求的通用图像创作。

**能做到的效果：**
- 根据中文长提示词生成完整画面。
- 描述人物外观、动作、环境和摄影信息。
- 按目标宽高建立对应尺寸的潜空间。
- 使用采样步数、CFG 和种子控制生成过程。
- 解码并保存最终图像。

**主要输入：** 中文或英文提示词、目标宽高、采样参数和随机种子；无需上传图片。

**核心模型与技术：** Qwen Image 2512、Qwen 文本编码、Qwen Image VAE、扩散采样。

## Y06-图像改为下一个场景图

**工作流类型：** 图像场景延续与语义编辑工作流

**主要用途：** 上传当前场景图片，通过编辑提示生成剧情中的下一个场景，在参考原人物和画面信息的同时改变动作、环境或镜头内容。

**能做到的效果：**
- 使用上传图片作为下一场景的视觉参考。
- 根据文本指令改变人物动作和场景状态。
- 延续参考图中的主体外观与核心元素。
- 按原图比例或指定尺寸生成新画面。
- 通过随机种子制作不同的场景候选。

**主要输入：** 一张当前场景图片、下一场景的中文编辑描述、目标尺寸、采样参数和随机种子。

**核心模型与技术：** 图像编辑模型、参考图条件、ReferenceLatent、VAE 编解码、语义场景转换。

## Y07-Klein-文生图

**工作流类型：** Flux Klein 文生图工作流

**主要用途：** 使用 Flux 2 Klein 根据文本提示直接生成图片，提供模型加载、尺寸、采样和输出所需的基础节点，可作为通用 Klein 文生图模板。

**能做到的效果：**
- 根据自然语言描述生成主体和场景。
- 使用正负向条件控制内容取舍。
- 自定义输出宽度、高度和批次数量。
- 调整采样步数、引导强度和随机种子。
- 解码、预览并保存生成图片。

**主要输入：** 正向提示词、负向提示词、目标宽高、批次数量、采样参数和随机种子；无需上传图片。

**核心模型与技术：** Flux 2 Klein、Qwen 文本编码、Flux2 VAE、Flux2Scheduler、潜空间文生图。

## Y08-四宫格-LTX-2.3图生视频优化版

**工作流类型：** 四宫格参考图驱动的 LTX 2.3 图生视频工作流

**主要用途：** 以四宫格图片作为多镜头视觉输入，结合视频提示词生成连续视频，适合将分镜草图转为短片段。

**能做到的效果：**
- 加载一张包含四个分镜的组合参考图。
- 使用四格画面提供人物、场景和镜头参考。
- 根据运动提示描述主体动作与镜头变化。
- 设置输出视频尺寸、帧数和帧率。
- 将采样结果解码并编码为视频文件。

**主要输入：** 一张四宫格参考图、视频内容与运动提示词、目标尺寸、帧数、采样参数和随机种子。

**核心模型与技术：** LTX 2.3、图像条件视频生成、文本编码、视频 VAE、视频采样与合成。
