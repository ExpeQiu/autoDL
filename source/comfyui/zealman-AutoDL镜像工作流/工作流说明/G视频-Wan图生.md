# G视频-Wan图生

本文档收录 `comfyui-workflow/G视频-Wan图生/` 目录下按 Windows 文件名自然排序的全部 26 个工作流。说明根据实际节点、上传输入及内部示例提示词整理。


## G01-图生视频-Wan2.2万相基础版

**工作流类型：** 首尾帧视频工作流

**主要用途：** 面向初学者的 Wan 2.2 图生视频基础流程。上传一张人物、产品或场景图片并填写中英文动作描述，即可生成数秒短视频，适合快速让静态素材产生人物动作、物体变化和简单运镜。

**能做到的效果：**
- 将单张参考图片转换为动态视频。
- 根据“人物向镜头挥手微笑”等提示控制主体动作。
- 自定义视频秒数、最长边分辨率和随机种子。
- 按 24 帧每秒自动计算生成帧数。
- 通过高噪与低噪双阶段采样兼顾动态和细节。
- 使用 LightX2V LoRA 以较少步数完成生成。

**主要输入：** 一张人物、产品或场景图片，中英文动作提示词，以及视频秒数、最长边分辨率、采样步数和随机种子。

**核心模型与技术：** Wan 2.2 I2V 14B 高噪/低噪模型、UMT5-XXL、Wan VAE、LightX2V I2V LoRA、双阶段 WanVideoSampler。

## G01-图生视频-Wan2.2优化版

**工作流类型：** 图生视频工作流

**主要用途：** 使用 Wan 2.2 I2V 将单张图片生成短视频，并对尺寸、时长、帧率、显存占用和采样速度进行集中优化。示例以轻微镜头摇晃、微风吹动叶片或头发为目标，适合制作自然微动、人物展示和环境氛围镜头。

**能做到的效果：**
- 让人物、植物或场景在保持原图构图的基础上自然运动。
- 用提示词控制轻微摇晃、风吹头发、风吹叶片等细节。
- 自定义宽度、高度、秒数和帧率。
- 使用高噪与低噪模型完成分段采样。
- 通过 LightX2V LoRA 和 Torch Compile 加速生成。
- 使用分块交换和显存清理降低运行压力。

**主要输入：** 一张参考图片、动作与运镜提示词、输出宽高、视频秒数、帧率和随机种子。

**核心模型与技术：** Wan 2.2 I2V A14B High/Low FP8、UMT5-XXL、Wan VAE、LightX2V I2V LoRA、Torch Compile、Block Swap、双阶段采样。

## G02-首尾帧-Wan2.2首尾帧视频

**工作流类型：** 图生视频工作流

**主要用途：** 以两张图片分别指定视频的起始画面和结束画面，再用分段动作提示词生成两者之间的连续过渡。内置示例描述角色完成 360° 转圈舞蹈并带动花瓣飘动，适合角色动作设计、首尾状态转换和镜头过渡制作。

**能做到的效果：**
- 分别锁定视频首帧和尾帧的主体、构图与状态。
- 在两张输入图之间生成连续自然的运动过程。
- 用时间分段提示描述旋转、抬腿、裙摆展开和花瓣漩涡。
- 通过 CLIP Vision 补充图像视觉条件。
- 使用 SLG 与 Enhance-A-Video 加强动作和画面表现。
- 通过高噪与低噪双阶段采样改善首尾衔接。

**主要输入：** 一张首帧图片、一张尾帧图片、中英文分段动作提示词，以及视频秒数、最长边分辨率、步数和随机种子。

**核心模型与技术：** Wan 2.2 I2V 14B 高噪/低噪模型、WanVideoImageToVideoEncode 首尾帧条件、OpenCLIP XLM-RoBERTa ViT-H、UMT5-XXL、SLG、Enhance-A-Video、双阶段采样。

## G03-图生视频-Wan2.2SmoothMix

**工作流类型：** 图生视频工作流

**主要用途：** 将一张图片生成短视频，并提供 Qwen 3.5 自动看图写词与手动分秒提示词两种输入方式。示例按 1—5 秒依次描述红发少女肩部纹身、耳饰、回眸和镜头拉远，适合制作按时间推进的角色展示镜头。

**能做到的效果：**
- 用单张参考图生成带分秒动作和运镜的视频。
- 自动分析图片并生成未来数秒的镜头描述，也可完全手写提示词。
- 通过 SmoothMix Wan 2.2 高噪/低噪模型分段采样。
- 将生成画面放大 2 倍，并用 RIFE 进行插帧。
- 同时预览基础帧率结果与 30 FPS 后处理结果。

**主要输入：** 一张参考图片、自动写词开关或手动分秒提示词、视频秒数、最长边、种子、步数和 CFG。

**核心模型与技术：** SmoothMix Wan 2.2 I2V/T2V High/Low、Qwen3.5 9B GGUF 与视觉投影模型、UMT5-XXL、Wan VAE、双阶段 KSampler、RIFE 4.9、Lanczos 放大。

## G04-图生视频-Wan2.2SmoothMix图生

**工作流类型：** 图生视频工作流

**主要用途：** 从单张图片生成 Wan 2.2 SmoothMix 视频，利用 Florence-2 反推画面内容并允许手动补充提示词。内部示例为白衣女子在月夜湖畔起舞、手势引动光鸟，包含近景、推进和俯拍镜头设计。

**能做到的效果：**
- 根据单张图片生成带主体动作和镜头运动的视频。
- 用 Florence-2 自动描述图片，并将图像类词汇替换为视频表达。
- 通过 CLIP Vision 补充视觉条件和尾帧相关信息。
- 使用 PusaV1 LoRA 配合高低噪双阶段采样。
- 输出基础视频，并提供 2 倍放大和 RIFE 插帧后的高帧率版本。

**主要输入：** 一张参考图片、手动或 Florence-2 自动提示词、视频秒数、最长边、目标尺寸、种子、步数和 CFG。

**核心模型与技术：** SmoothMix Wan 2.2 I2V/T2V High/Low、Wan21 PusaV1 LoRA、Florence-2 PromptGen、CLIP Vision H、UMT5-XXL、Wan VAE、RIFE 4.9、ColorMatch。

## G05-图生视频-Wan2.2+LightX2V最强动态

**工作流类型：** 图生视频工作流

**主要用途：** 把单张图片转换为强调动作幅度和运镜的 Wan 2.2 短视频。提示词既可手动填写，也可调用豆包看图反推并附加场景、情绪、运镜、光线和焦距选项；示例描述白衣女子在湖畔起舞并引动光鸟。

**能做到的效果：**
- 让单张人物或场景图片产生连续动作。
- 手动写词或通过豆包 API 自动反推视频描述。
- 用预设选择器补充场景、情绪、运镜、光线和镜头焦距。
- 使用多组 LightX2V 与 Wan 2.2 Fun LoRA强化动态表现。
- 输出基础 16 FPS 视频和 RIFE 插帧后的 32 FPS 视频。

**主要输入：** 一张参考图片、手动提示词或豆包 API 自动提示词、场景与镜头选项、视频秒数、最长边、种子和采样参数。

**核心模型与技术：** Wan 2.2 I2V 14B High/Low、LightX2V I2V LoRA、Wan 2.2 Fun InP LoRA、豆包视觉反推、CLIP Vision H、UMT5-XXL、Wan VAE、RIFE 4.9、SageAttention。

## G06-首尾帧-Wan2.2+LightX2V超动感

**工作流类型：** 首尾帧视频工作流

**主要用途：** 用两张图片锁定起始和结束画面，生成两者之间的动态过渡。内置提示词描述东亚女性站在清晨野花草坪中，镜头缓慢推进，发丝与裙摆随风运动，并可使用 Qwen 3.5 根据图片辅助写词。

**能做到的效果：**
- 分别输入首帧和尾帧，控制视频两端画面。
- 用 CLIP Vision 对两张图片进行视觉编码。
- 根据分秒提示控制推进运镜、人物细微动作和环境动态。
- 通过 PusaV1 与 LightX2V LoRA增强过渡动态。
- 使用 NAG、CFG Zero Star 和高低噪双阶段采样生成 24 FPS 视频。

**主要输入：** 一张首帧图片、一张尾帧图片、手动或 Qwen 3.5 自动提示词、输出宽高、帧数、种子和采样参数。

**核心模型与技术：** Wan 2.2 I2V 14B High/Low、WanFirstLastFrameToVideo、LightX2V I2V LoRA、Wan22 PusaV1 LoRA、Qwen3.5 9B GGUF、CLIP Vision H、NAG、CFG Zero Star。

## G07-图生视频-Wan2.2+LightX2V-WorkFisher

**工作流类型：** 图生视频工作流

**主要用途：** 面向单图动态化的 Wan 2.2 LightX2V 四步流程，并提供 Qwen 3.5 自动看图写词。示例按秒描述赛博都市中的银发角色、蓝色星光耳饰、霓虹灯牌和镜头推近，适合制作节奏明确的角色氛围短片。

**主要输入：** 一张参考图片、手动或 Qwen 3.5 自动提示词、视频秒数、最长边、种子和采样参数。

**核心模型与技术：** Wan 2.2 I2V LightX2V 四步 High/Low、LightX2V I2V LoRA、Wan 2.2 Fun InP LoRA、Qwen3.5 9B GGUF、UMT5-XXL、Wan VAE、RIFE 4.7、SageAttention。

## G09-长视频-Wan2.2StoryMem多分镜无限

**工作流类型：** 长视频工作流

**主要用途：** 以一张起始图片和逐行分镜文本循环生成连续视频片段，通过 StoryMem 潜空间记忆衔接前后镜头。内部示例由多行英文场景组成，依次安排精品店、城市屋顶等不同镜头。

**能做到的效果：**
- 从起始图生成第一段视频并循环续接后续分镜。
- 从文本文件逐行读取不同场景提示词。
- 抽取上一段的关键帧与尾帧作为下一段条件。
- 通过 StoryMem Latents保留跨片段的视觉信息。
- 分别生成各段临时视频，便于检查多分镜结果。

**主要输入：** 一张起始参考图、按行保存的分镜提示词文本、循环次数、输出宽高、单段帧数、帧率、种子和采样参数。

**核心模型与技术：** Wan 2.2 I2V/T2V A14B High/Low、StoryMem Latents、MI2V Backbone LoRA、LightX2V I2V/T2V LoRA、ForLoop、关键帧抽取、双阶段 WanVideoSampler。

## G11-长视频-SVIPro长视频

**工作流类型：** 长视频工作流

**主要用途：** 从一张参考图片连续生成三段视频，并用重叠帧混合衔接成长镜头。示例依次描述女子向前行走并挥手、走向服装店、在橱窗外驻足观看。

**能做到的效果：**

- 为每一段分别填写正向提示词和采样种子。
- 从前一段画面延续下一段的图像条件。
- 通过重叠帧线性混合减轻片段接缝。
- 分段预览并输出合并后的连续视频。

**主要输入：** 一张参考图片、三段动作与运镜提示词、视频宽高、每段帧数、帧率、重叠帧数和采样参数。

**核心模型与技术：** Wan 2.2 I2V LightX2V High/Low、SVI v2 Pro High/Low LoRA、WanAdvancedI2V SVI 模式、ImageBatchExtendWithOverlap、双阶段 KSampler、Wan VAE。

- 将自动结果按空行拆分并分配到各段采样。
- 最多配置 12 段图生视频续接。
- 用上一段输出和重叠帧混合维持动作连续性。
- 可逐段预览，并按实际生成段数连接最终合并结果。

**主要输入：** 一张参考图片、分镜生成要求或手动多段提示词、启用的分镜段数、视频宽高、每段帧数、帧率、重叠帧数和种子。

**核心模型与技术：** Wan 2.2 Remix I2V High/Low、SVI v2 Pro High/Low LoRA、LightX2V LoRA、Qwen3-VL 8B GGUF、WanAdvancedI2V SVI 模式、Split String、重叠帧线性混合。

**工作流类型：** 长视频工作流
