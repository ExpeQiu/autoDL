# S图像-Boogu

本文档收录 `comfyui-workflow/S图像-Boogu/` 目录下的全部工作流。说明根据工作流名称、实际节点、上传输入及内部示例提示词整理。


## S01-boogu文生图

**工作流类型：** 文生图工作流

**主要用途：** 面向中文自然语言的 Boogu Turbo 快速文生图流程。用户输入画面描述并选择分辨率后，通过四步 LCM 采样快速生成图片，适合运营海报、3D 插画、宣传素材和竖屏视觉内容。

**能做到的效果：**
- 使用中文提示词直接生成图片。
- 选择常用分辨率或自定义画面宽高。
- 通过四步 LCM 快速完成采样。
- 生成带创意字体、人物和复杂背景的插画海报。
- 使用随机种子重复或变化生成结果。

**主要输入：** 中文提示词、输出分辨率和随机种子，无需上传图片。

**核心模型与技术：** Boogu Image Turbo、Qwen3-VL 8B、Flux1 VAE、LCM 采样。

## S02-boogu图像编辑

**工作流类型：** 图生图与图像编辑工作流

**主要用途：** 基于 Boogu Image Edit 对单张图片执行中文语义编辑。上传原图并输入修改指令后，可替换背景、调整场景或改变画面内容，同时按原图比例缩放处理，适合快速改图和创意重绘。

**能做到的效果：**
- 根据中文自然语言指令编辑上传图片。
- 替换背景或改变人物所处环境。
- 在编辑时保留原图主体与整体构图参考。
- 按原始宽高比缩放，并以最长边控制处理尺寸。
- 调节采样步数、CFG、降噪强度和随机种子。

**主要输入：** 一张待编辑图片、中文编辑提示词、目标最长边尺寸和随机种子。

**核心模型与技术：** Boogu Image Edit、Qwen3-VL 8B、Flux1 VAE、TextEncodeBooguEdit、AuraFlow Model Sampling、DPM++ 2M。
