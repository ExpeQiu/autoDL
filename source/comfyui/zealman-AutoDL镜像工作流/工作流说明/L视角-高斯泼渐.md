# L视角-高斯泼渐

本文档收录 `comfyui-workflow/L视角-高斯泼渐/` 目录下的全部工作流。说明根据工作流名称、实际节点、上传输入及内部示例提示词整理。


## L01-视角改变-高斯泼溅3D改角度V1

**工作流类型：** 图生图、3D 高斯泼溅与图像编辑综合工作流

**主要用途：** 围绕单张场景图片进行三维视角改造。工作流可先估计 3D 高斯场景并导出、预览 PLY，也可通过相机参数生成新观察角度，再利用 Qwen 图像编辑修复透视、空白区域和画面细节，适合场景换视角和镜头预演。

**能做到的效果：**
- 从单张图片估计 3D 高斯并导出 PLY。
- 调节水平角、垂直角和缩放生成多种相机视角。
- 使用原图和高斯渲染图进行双图参考编辑。
- 修复新视角中的透视、空白区域、水印和 LOGO。
- 对比原图、高斯视角图和最终修复图。

**主要输入：** 一张场景图片、相机视角参数及图像编辑提示词。

**核心模型与技术：** ComfyUI-Sharp、GeometryPack、3D Gaussian Splatting、Qwen Image Edit 2511、Qwen 多角度 LoRA、高斯泼溅 LoRA。

## L02-视角改变-高斯泼溅3D改角度V2

**工作流类型：** 图生图、3D 高斯泼溅与图像编辑综合工作流

**主要用途：** 从单张图片预测 3D 高斯场景并直接渲染新视角，再分别使用 Qwen Image Edit 2511 和 2509 路线修复透视与缺失区域，适合快速换机位、比较不同编辑模型并输出完整场景视角图。

**能做到的效果：**
- 从输入图估计高斯场景并生成 PLY、外参和内参。
- 在 GaussianViewer 中交互改变机位并输出对应视角图。
- 以原图和高斯渲染图作为双图参考修复透视与空白区域。
- 对比 Qwen Image Edit 2511、2509 与原始高斯视角的结果。
- 通过 Lightning 与高斯泼溅 LoRA 加速并强化视角修复。

**主要输入：** 一张场景图片及用于约束透视修复、场景保持和空白补全的编辑提示词。

**核心模型与技术：** ComfyUI-Sharp、GaussianViewer、3D Gaussian Splatting、Qwen Image Edit 2511/2509、Qwen Image Lightning、高斯泼溅 LoRA。
