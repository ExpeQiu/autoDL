# P视频-动作迁移

本文档收录 `comfyui-workflow/P视频-动作迁移/` 目录下按 Windows 文件名自然排序的全部 21 个工作流。说明依据各 JSON 中的实际节点、主要输入、模型配置、分组说明和示例提示词整理。

## P01-动作迁移-Wan多人姿态迁移最强版高配24G

**工作流类型：** 多人分割与姿态驱动的 Wan 2.2 Animate 动作迁移工作流

**主要用途：** 使用人物参考图和动作视频生成新角色表演，并通过对象遮罩处理多人场景；示例提示词为“三个女人在跳舞”。

**能做到的效果：**
- 从驱动视频提取全身姿态和面部条件。
- 使用 SAM3 按对象 ID 分割单人或多人。
- 通过 SDPose、ViTPose 与 YOLO 处理人体和面部关键点。
- 可接入 Uni3C 增强原视频中的镜头运动。
- 支持多组 LoRA 加速、补光及质量增强。
- 输出生成结果、姿态/遮罩预览和对比画面。

**主要输入：** 人物参考图、动作驱动视频、SAM3 人物文本描述或打点结果、动作提示词、对象 ID、输出尺寸与帧数。

**核心模型与技术：** Wan 2.2 Animate 14B、SAM3、SDPose WholeBody、ViTPose、YOLOv10、Uni3C ControlNet、CLIP Vision、多 LoRA。

**视频教程：** https://www.bilibili.com/video/BV1P4rkBcEZR/?spm_id_from=333.1387.homepage.video_card.click&vd_source=30b3fed7dfde8379c4ba83f85224199b

## P02-动作迁移-Wan2.2Animate角色迁移

**工作流类型：** 单图角色与视频驱动的 Wan 2.2 Animate 动作迁移工作流

**主要用途：** 把视频中的人物动作和面部运动迁移到一张角色参考图，示例提示词为“一个女生正在跳舞”。

**能做到的效果：**
- 用一张角色图重建驱动视频中的表演主体。
- 逐帧检测身体、手部姿态和人脸区域。
- 将姿态图、面部图和参考角色共同用于生成。
- 支持按秒数、尺寸和帧率控制读取范围。
- 可把驱动视频音频合并到输出视频。
- 支持 Lightning、Pusa、Relight、HPS 与 FastWan LoRA。

**主要输入：** 一张角色参考图、一段动作驱动视频、动作描述提示词、处理秒数、输出宽高与帧率。

**核心模型与技术：** Wan 2.2 Animate 14B、WanVideoWrapper、PoseAndFaceDetection、ViTPose、YOLOv10、CLIP Vision、多 LoRA。
