# A图像-Qwen生成

本文档收录该目录全部工作流，共 10 个，按 Windows 文件名自然排序排列。说明根据实际节点、上传输入及内部示例提示词整理。

## A01-文生图-Qwen2512高清放大

**工作流类型：** 文生图综合工作流

**主要用途：** 基于 Qwen Image 2512 从文字提示直接生成图片，支持可选的写实人像 LoRA 与 Lightning 加速采样。生成结果会经过 SeedVR2 智能放大和色彩调整，适合制作高清写实人像、视觉素材及通用题材图片。

**能做到的效果：**
- 使用中英文提示词从零生成图片。
- 自定义画面宽高、种子和正负向提示词。
- 可开启真实幻想、极致真实等人像 LoRA 增强质感。
- 通过 Lightning LoRA 提高采样速度。
- 使用 SeedVR2 将图片放大至约 2048 级并自动调色。

**主要输入：** 正向提示词、负向提示词、画面尺寸和随机种子，无需上传图片。

**核心模型与技术：** Qwen Image 2512、Qwen2.5-VL 7B、Lightning LoRA、SeedVR2、LayerColor 自动调色。

## A02-文生图-Qwen无限素材多分镜多角度

**工作流类型：** 图生图与图像编辑综合工作流

**主要用途：** 以单张图片为起点，先用本地 Qwen3-VL 反推主体、场景和视觉信息，再自动生成连续分镜文本或调用预设镜头指令，批量制作同一素材的后续场景与多角度画面。适合故事板、镜头预演和角色一致性素材扩展。

**能做到的效果：**
- 从单张图片反推主体、前中后景、构图和光影描述。
- 根据叙事模板自动生成多段连续电影分镜提示词。
- 按提示词逐行生成同一人物或场景的后续镜头。
- 快速切换前移、旋转、俯视、仰视、广角和特写等视角。
- 使用不同分镜或角度指令持续扩展图片素材。
- 通过 Next Scene 与多角度 LoRA 加强镜头变化和内容延续。

**主要输入：** 一张人物或场景图片、分镜生成要求或多行镜头指令、最长边尺寸和随机种子。

**核心模型与技术：** Qwen Image Edit 2509、Qwen3-VL 8B、Next Scene LoRA、Multiple Angles LoRA、Lightning LoRA、F2P LoRA、逐行提示词处理。

## A03-洗图-Qwen洗图大合集

**工作流类型：** 图生图综合工作流

**主要用途：** 集成写实、奇幻和二次元转真人等多套 Qwen Image 洗图流程。工作流可用 Qwen3-VL 反推原图内容，并结合姿势、深度或边缘控制重建构图，再通过不同风格 LoRA 和 SeedVR2 输出高清新图，适合低清素材重绘、画风转换和人物质感升级。

**能做到的效果：**
- 根据原图内容自动生成适合重绘的中文提示词。
- 使用姿势、深度和边缘信息约束人物动作与构图。
- 将普通图片重绘为写实人像或更具摄影质感的画面。
- 将动漫、插画角色转换为真人化或奇幻风格。
- 通过多组 LoRA 切换写实、动漫、幽灵感等视觉方向。
- 使用 SeedVR2 放大重绘结果并增强细节。

**主要输入：** 一张待重绘图片，可选姿势参考图，以及风格提示词、输出尺寸和随机种子。

**核心模型与技术：** Qwen Image、Qwen3-VL 8B、Qwen Image InstantX ControlNet Union、DWPose/Depth/Canny 预处理、Lightning 与多风格 LoRA、SeedVR2。

- 切换前移、左右旋转、俯仰、广角和特写等镜头。
- 保持参考图主体信息并延续后续场景。
- 在两套独立分支中分别完成自动分镜和多角度生成。

**主要输入：** 一张人物或场景图片、分镜数量或多行镜头指令、最长边尺寸和随机种子。

**核心模型与技术：** Qwen Image Edit 2509、Qwen3-VL 8B GGUF、Next Scene LoRA、Multiple Angles LoRA、Lightning 8 步 LoRA、F2P LoRA、逐行提示词处理。

## A06-图生图-QwenControlNet

**工作流类型：** 图生图工作流

**主要用途：** 以单张图片同时作为初始潜空间和 ControlNet 条件，按文字提示重绘画面。默认提取 OpenPose 姿态，也可切换深度或边缘预处理，适合在保留动作和结构的前提下改变人物外观。

**能做到的效果：**
- 从参考图提取人体姿态并约束生成结果。
- 通过中文提示修改发色、角色类型或画面内容。
- 可切换 OpenPose、Depth 与 Canny 等控制方式。
- 利用原图潜空间保留整体构图和画面比例。
- 将控制图与生成结果横向拼接便于比较。

**主要输入：** 一张参考图片、正向提示词、负向提示词、ControlNet 类型和随机种子。

**核心模型与技术：** Qwen Image、Qwen2.5-VL 7B、Qwen Image ControlNet Union、OpenPose/Depth/Canny 预处理、Lightning 8 步 LoRA、AuraFlow 采样。
