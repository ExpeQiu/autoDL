# B图像-Qwen编辑

本文档收录该目录全部工作流，共 17 个，按 Windows 文件名自然排序排列。说明根据实际节点、上传输入及内部示例提示词整理。


## B01-编辑-Qwen编辑合集

**工作流类型：** 图生图与图像编辑综合工作流

**主要用途：** 集成单图指令编辑、双图姿势迁移和人物换装三套 Qwen Image Edit 方案。可以根据中文指令修改原图，也可以利用第二张图片提供姿势或服装参考，适合人物改图、造型设计和角色一致性素材制作。

**能做到的效果：**
- 根据文字指令修改人物姿态、场景和画面内容。
- 将参考人物迁移到另一张图片的姿势上。
- 让第一张图中的模特穿上第二张图中的服装。
- 使用 DWPose 提取参考图片的身体姿态。
- 输出原图、参考图和编辑结果的对比画面。

**主要输入：** 根据所选功能上传一至两张图片，并填写中文编辑指令。

**核心模型与技术：** Qwen Image Edit 2509、DWPose、Consistence LoRA、Lightning LoRA、Qwen Image Edit Plus Advance。

## B02-编辑-Qwen2511单双三图编辑

**工作流类型：** 单图、双图与三图参考图像编辑综合工作流

**主要用途：** 基于 Qwen Image Edit 2511 提供单图、双图和三图三套独立编辑流程。既能按照文字指令改造主图，也能从其他图片提取物体、服装或风格并融合到主图中，适合人物改造、产品组合和多素材创意合成。

**能做到的效果：**
- 单图修改发色、服装、节日主题、场景和画面细节。
- 双图将参考物体加入主图，例如让人物抱住参考图片中的小猫。
- 三图同时组合人物、物体和服装等多种参考内容。
- 使用 ReferenceLatent 保留各张参考图的视觉信息。
- 自动按最长边缩放输入并保持画面比例。
- 输出原图、参考图和编辑结果的对比画面。

**主要输入：** 根据模式上传一至三张图片，填写中文编辑指令，并设置最长边尺寸和随机种子。

**核心模型与技术：** Qwen Image Edit 2511、Qwen2.5-VL 7B、Lightning 4 步 LoRA、F2P LoRA、ReferenceLatent、CFGNorm。

## B03-编辑-Qwen2511单双三图编辑V2

**工作流类型：** 单图、双图与三图参考图像编辑综合工作流

**主要用途：** Qwen Image Edit 2511 的单、双、三图编辑 V2 流程，按素材数量划分为三套可独立运行的分支。内置圣诞人像改造、人物抱猫和人物穿参考服装等示例，可用于自然语言改图及多参考图语义融合。

**能做到的效果：**
- 用单张主图完成人像造型、发色和场景主题改造。
- 使用第二张图片为主图补充指定人物、物体或环境参考。
- 使用三张图片组合人物、小猫、服装等不同素材。
- 通过双路条件与 ReferenceLatent 汇集多图参考信息。
- 使用四步采样快速生成编辑结果。
- 自动整理原图、参考图与最终效果用于对照。

**主要输入：** 一至三张参考图片、中文编辑提示词、最长边尺寸和随机种子。

**核心模型与技术：** Qwen Image Edit 2511 FP8 Mixed、Qwen2.5-VL 7B、Lightning 4 步 LoRA、F2P LoRA、ReferenceLatent、CFGNorm。

## B04-编辑-Qwen2511多角度多场景分镜

**工作流类型：** 图像编辑综合工作流

**主要用途：** 以单张人物或场景图为基础，在两套独立分支中生成连续故事分镜或多角度镜头。自动分镜分支会先反推视觉信息并编写连续场景，另一分支可直接执行预设镜头变化指令。

**能做到的效果：**
- 反推参考图的主体、前中后景、构图、色调和光影。
- 自动生成具有时空连续性的多段电影分镜。
- 按行批量执行 `Next Scene` 场景描述。
- 切换前移、旋转、俯视、仰视、广角和特写等角度。
- 延续人物外观、环境基调和叙事情节。
- 分别输出自动分镜与预设多角度结果。

**主要输入：** 一张参考图片、分镜段数或多行镜头指令、最长边尺寸和随机种子。

**核心模型与技术：** Qwen Image Edit 2511、Qwen3-VL 4B、Multiple Angles LoRA、Lightning 4 步 LoRA、ReferenceLatent、逐行提示词处理。

## B06-编辑-Qwen2509极限姿态参考

**工作流类型：** 图像编辑综合工作流

**主要用途：** 通过人物图和姿态参考图进行服装迁移、动作迁移及细节修复。流程先完成服装或外观编辑，再提取深度信息辅助姿势迁移，并提供超分与低降噪二次采样。

**能做到的效果：**
- 让人物穿上另一张图中的服装。
- 将人物替换为姿态参考图中的动作。
- 先将复杂背景转换为灰色背景以减少干扰。
- 使用深度图加强身体姿态和空间结构。
- 对中间结果放大后进行低降噪细化。
- 保留人物外观并处理较大幅度姿势变化。

**主要输入：** 一张人物图、一张服装或姿态参考图，以及发型、服装、动作和背景编辑指令。

**核心模型与技术：** Qwen Image Edit 2509、DepthAnythingV2、Lightning 8 步 LoRA、Qwen Image Edit Plus、4x NMKD 超分、分块 VAE。

## B07-编辑-Qwen极速换脸

**工作流类型：** 图像编辑工作流

**主要用途：** 将上传的人脸或头部参考融合到目标人物场景中。流程自动分离参考图头发与面部区域，生成柔化遮罩后在目标图局部重绘，并可一次采样多个候选结果。

**能做到的效果：**
- 将参考角色头部置入目标人物画面。
- 自动提取脸部与头发区域。
- 扩张、模糊遮罩以改善融合边缘。
- 只重绘人物头部附近并保留场景其他区域。
- 批量生成多个候选结果供选择。

**主要输入：** 一张人脸或人物参考图、一张目标场景图、生成数量、最长边和一致性 LoRA 强度。

**核心模型与技术：** Qwen Rapid AIO、Consistence Edit LoRA、F2P LoRA、PersonMaskUltra V2、InpaintModelConditioning、Differential Diffusion。
