# Z工具设置

本文档收录全部 `comfyui-workflow/Z工具设置/` 目录下的工作流，按 Windows 文件名自然排序。说明根据工作流名称、实际节点、上传输入及内部示例提示词整理。


## Z01-工具-ZealmanAPI示例

**工作流类型：** API 工具综合工作流

**主要用途：** 展示 Zealman Comfyui-MyApi 插件中多种云端服务的独立调用方式，包含文本对话、多模态理解、图片问答、文生图、参考图生图和翻译，适合测试 API Key、学习节点参数及搭建云端 AI 工作流。

**能做到的效果：**
- 调用 DeepSeek V4 Pro 进行文本问答和内容生成。
- 使用 AutoDL API 节点向 Qwen3.6 Plus 提交文本或最多五张图片。
- 通过豆包 Seed 视觉模型理解最多五张参考图。
- 使用 Seedream 根据文字或最多十张参考图生成图片。
- 设置 2K 或自定义输出尺寸、随机种和是否添加水印。
- 使用豆包 Seed Translation 在指定语言之间翻译文本。

**主要输入：** 对应服务的 API Key、文本提示词，以及部分功能需要的参考图片。

**核心模型与技术：** Zealman Comfyui-MyApi、DeepSeek V4 Pro、Qwen3.6 Plus、豆包 Seed 2.0 Pro、Seedream 4.5、Seed Translation。

## Z02-工具-通用替换模组

**工作流类型：** 图像与视频反推工具综合工作流

**主要用途：** 提供多组可独立使用的本地视觉理解模组，用不同 Qwen、Gemma 模型对图片或视频生成中文描述和提示词。适合反推图像内容、分析视频动作，以及比较不同视觉语言模型的输出。

**能做到的效果：**
- 使用 Qwen3.5 9B 对单张图片生成中文提示词。
- 使用 Gemma 4 26B 对同一图片进行独立反推。
- 使用 Qwen3.6 35B 生成另一组图片描述结果。
- 读取视频帧并由 Qwen3.5 或 Gemma 4 描述视频内容。
- 按每秒拆解视频中的表情、动作和手势变化。
- 使用 Qwen3 VQA 按导演模板生成首中尾帧转场描述。

**主要输入：** 一张待反推图片或一段待分析视频，以及自定义描述规则、采样参数和随机种子；各模组按需单独运行。

**核心模型与技术：** Qwen3.5 9B GGUF、Gemma 4 26B A4B GGUF、Qwen3.6 35B GGUF、Qwen3-VL 4B、llama.cpp VLM、Video Helper Suite。

## Z03-工具-批量描述生成器

**工作流类型：** 批量提示词生成工具工作流

**主要用途：** 使用本地 Qwen3-VL 根据提示词结构、关键词库、追加要求和固定 LoRA 触发词，一次生成多条人物与场景描述，再按触发词自动拆分为独立文本。适合批量准备文生图或视频生成提示词。

**能做到的效果：**
- 将主体、环境、运动、风格、镜头和光影规则组合为系统提示。
- 固定追加指定 LoRA 触发词到每条描述开头。
- 按示例要求一次生成八条新的女孩与场景提示词。
- 生成包含人物造型、动作、构图、运镜和色调的中文描述。
- 使用触发词作为分隔关键字自动拆分批量结果。
- 将拆分后的多条提示词分别输出，便于后续接入生成节点。

**主要输入：** 提示词结构说明、关键词库、生成数量与内容要求、固定 LoRA 触发词，以及本地模型采样参数；无需上传图片。

**核心模型与技术：** Qwen3-VL 8B GGUF、llama.cpp VLM、Text Concatenate、segment_text、ComfyLiterals、多路文本输出。

## Z04-设置-ComfyUI批量加载

**工作流类型：** 图片目录批量加载与队列控制工具工作流

**主要用途：** 演示从指定目录连续读取图片并传入后续节点的配置方式，适合批量反推、编辑、放大或保存任务。

**能做到的效果：**
- 从目录中按文件顺序加载图片。
- 设置起始索引和每批读取数量。
- 将图片列表转换为可逐张处理的批次。
- 在重复队列中自动推进待处理文件。
- 输出文件名等信息供后续保存节点使用。

**主要输入：** 图片目录、文件筛选或排序条件、起始索引、批量大小和队列次数。

**核心模型与技术：** 目录图像加载、批次迭代、列表处理、队列控制、文件名传递。

## Z05-设置-ComfyUI视频帧数设置

**工作流类型：** 视频时长、帧率与生成帧数计算工具工作流

**主要用途：** 根据目标时长和帧率计算视频工作流需要生成或加载的帧数，便于统一视频采样与输出参数。

**能做到的效果：**
- 使用时长与帧率计算基础总帧数。
- 将计算结果调整为视频模型适用的帧数格式。
- 同步生成帧数与输出视频帧率。
- 减少手工换算造成的时长偏差。
- 将整数结果连接到后续视频节点。

**主要输入：** 目标视频时长、目标帧率，以及工作流要求的帧数步进参数。

**核心模型与技术：** 数学表达式节点、整数转换、帧数对齐、参数联动。

## Z06-设置-API重复调用清缓存

**工作流类型：** ComfyUI API 循环调用与缓存清理工具工作流

**主要用途：** 演示在 API 连续提交相似任务时更改运行标记并清理模型或节点缓存，使每次请求按预期重新执行。

**能做到的效果：**
- 为重复 API 请求提供可变化的执行参数。
- 避免相同输入直接复用上一轮节点结果。
- 在任务间触发缓存或显存清理。
- 配合队列循环连续执行多次工作流。
- 将清理步骤放在指定处理阶段之间。

**主要输入：** API 请求参数、循环次数、每轮变化值和缓存清理开关。

**核心模型与技术：** Cache 清理、VRAM 卸载、队列触发、随机值或计数器、API 参数联动。

## Z07-设置-最后一帧输出图像

**工作流类型：** 视频末帧提取工具工作流

**主要用途：** 从视频或图像批次中选取最后一帧并另存为图片，可用于首尾帧续作、下一段视频参考或结果检查。

**能做到的效果：**
- 加载视频并取得完整图像帧批次。
- 根据批次长度定位最后一帧。
- 从批次中单独提取末帧图像。
- 预览并保存最后一帧。
- 将末帧继续传给图生视频或图像编辑节点。

**主要输入：** 一段视频或一组按时间排序的图像帧。

**核心模型与技术：** Video Helper Suite、图像批次计数、按索引取帧、末帧保存。

## Z08-设置-视频补帧

**工作流类型：** 视频帧插值与帧率提升工作流

**主要用途：** 对上传视频执行相邻帧插值，增加中间帧并按新帧率重新输出，使运动过渡更连续。

**能做到的效果：**
- 从视频中读取连续画面帧和原始音频。
- 在相邻原始帧之间生成补间帧。
- 按倍率提高输出帧数和帧率。
- 保持输出画面尺寸与输入一致。
- 将补帧结果与音频重新合成为视频。

**主要输入：** 一段待补帧视频、插帧倍率、输出帧率和视频编码参数。

**核心模型与技术：** RIFE 帧插值、Video Helper Suite、批量帧处理、视频重编码。

## Z09-视频补帧-防丢帧-防偏色

**工作流类型：** 视频帧插值、帧数校正与色彩保持工作流

**主要用途：** 在常规视频补帧基础上校验帧数和输出时序，并对处理结果执行色彩匹配，减少重编码中的丢帧与明显偏色。

**能做到的效果：**
- 读取原视频帧率、帧数和音频信息。
- 对相邻画面执行多倍帧插值。
- 根据输入帧数计算预期输出帧数。
- 对批次进行校正，减少首尾或中间帧遗漏。
- 使用色彩匹配减小补帧前后的颜色变化。
- 按校正后的帧率重新封装视频。

**主要输入：** 一段待补帧视频、插帧倍率、帧数校正、色彩匹配和编码参数。

**核心模型与技术：** RIFE、帧数计算与批次校正、ColorMatch、Video Helper Suite、视频重编码。

## Z11-XY图表测试工作流

**工作流类型：** 生成参数 XY 对比测试工作流

**主要用途：** 将两组待测试参数分别放在 X 轴和 Y 轴，批量运行相同生成流程并拼成对比图，用于观察参数组合对结果的影响。

**能做到的效果：**
- 在 X 轴设置一组模型或采样参数候选值。
- 在 Y 轴设置另一组参数候选值。
- 自动遍历两轴组合并执行生成任务。
- 使用固定提示词和种子进行可比测试。
- 将结果按坐标位置拼接并标注参数信息。

**主要输入：** 固定生成提示词、X 轴参数列表、Y 轴参数列表、基础尺寸和随机种子。

**核心模型与技术：** XY Plot、参数列表遍历、固定种子对比、图像网格拼接、文本标注。
