## 视频参数规则

省略的字段用默认值。写出的字段先按「可写范围」拒绝，再按「生效」收口。参考图可以是本地路径（仅 CLI）、`data:` URL、`http(s)` 或纯 base64，单张不超过 20MB，仅 png / jpg / webp。

| 参数 | 可写范围 | 默认 | 生效 |
|------|----------|------|------|
| `prompt` | 1–8000 字 | 必填 | 原样写入采样器 |
| `play_mode=text` | 不能带图 | 无图时 | `t2v.u03`，不接首尾帧 |
| `play_mode=first_frame` | 恰好 1 张 `image_ref`，不能有尾帧 | — | `t2v.i2v` |
| `play_mode=first_last_frame` | 1 张 `image_ref` + 1 张 `end_image_ref` | — | `t2v.flf2v` |
| `play_mode=multi` | `image_refs` 2–9 张，不能有尾帧 | — | `t2v.r2v`，提示词用 `<Picture 1>` 起 |
| `play_mode=omni` / 图生图 | — | — | `422`。参考视频和音频不在本卡 |
| `width` / `height` | 64–4096 | 768 / 768 | 夹到 256–1344，再向下对齐 16 |
| `duration` + `fps` | 时长 0–60 秒，帧率 1–60 | 帧数 73 | `duration>0` 时帧数 = round(时长×帧率)，再向上对齐 `17k+5`，上限 124。`duration` 为 0 或省略则用 73，忽略 `fps` |
| `steps` | 1–8 | 4 | 原样。Turbo LoRA 按 4 步设计 |
| `seed` | 整数 | 随机 | `-1` 或省略为随机 |

CLI 与 `POST /v1/jobs` 使用同一套字段。`--images` 用 `|` 分隔路径。`play_mode` 省略时：无图为文生，1 张为单图，1 张加尾帧为首尾帧，2 张及以上为多图。

编排 API（最小集）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/health` | 编排存活 |
| GET | `/v1/compute/health` | ComfyUI `/system_stats` 或 Mock |
| POST | `/v1/jobs` | 提交任务 |
| GET | `/v1/jobs/{id}` | 查询 |
| GET | `/v1/jobs` | 列表 |
| GET | `/v1/jobs/stats` | 评测统计（成功率、耗时分位、评分分布、token） |
| PATCH | `/v1/jobs/{id}/score` | 人工 1–5 分 |
| DELETE | `/v1/jobs/{id}` | 删除单条任务及产物 |
| DELETE | `/v1/jobs` | 批量清理（可按 `provider`） |
| GET | `/v1/services` | 对外服务目录（文/图/视频）；`?exposed=true` 只看已暴露 |
| PUT | `/v1/services` | 整表保存；缺 id 才补默认，不盖回 `exposed=false` |
| PATCH | `/v1/services/{id}` | 改单条暴露开关 / 名称 / 说明 |
| GET/PUT | `/v1/access` | 服务接入：编排 Mock/模型 + 本地 / autodl 地址 + 租赁 SSH（密码不回传）；文/图/视频通道独立，已保存不被 .env 盖回 |

任务额外字段（评测）：`elapsed_ms`、`model`、`prompt_tokens` / `completion_tokens`、`started_at` / `finished_at`、`output_bytes` / `output_chars`、`score`。

服务目录真源：`data/services.json`（gitignore）。默认 `llm.chat` / `t2i.demo` / `t2v.u03` 全暴露。接入真源：`data/access.json`（`profile=local|autodl`，本地与租赁路径分套）。Web：`/services` 服务配置。CLI：`autodl service list`。决策见 `ADR/ADR-003-服务暴露目录.md`。

ComfyUI 直连协议不改：`POST /prompt` → 轮询 `/history/{id}` → `/view`。详见上级 `comfyui/comfyui&autodl.md`。

## 增量（≤2 天）

| 增量 | DoD |
|------|-----|
| **P0** 脚手架 + Mock | `start` 后 `/health` 200；Mock 三种 modality 出假结果；`verify.sh` 非 0 失败 |
| **P1** 文生图 | 隧道通；一条 t2i 在超时内返回真实 `/view` |
| **P2** 文生视频 | `AI_MOCK_MODE=false` 时 `t2v.u03` 异步提交 MiniMax H3，mp4 回结果墙；verify 不真跑 GPU |
| **P3** 文本 LLM | 工厂 + env；Mock 不打外网 |
| **P4** 结果墙 | Next 列表 / 预览 / 人工 1–5 分 · `http://127.0.0.1:3190/` |
| **P5** 服务配置 | `/v1/services` + `/v1/access` + Web `/services`；文/图/视频可关发现且 Mock/Host 刷新不盖回 |

## 观测

日志 JSON，必带 `run_id` / `job_id` / `modality` / `provider`（服务目录另带 `service_id`）。落 `logs/orchestrator.log`。

## 反模式

- 业务代码写 AutoDL 公网 IP 或动态 SSH 端口
- 把 `guide/服务器&ssh.md` 的密码拷进 `.env.example`
- 在本仓再做一套画布
- 无 `stop.sh`、无 `run_id`
- 已保存的 `exposed=false` 被 `.env` 或目录默认翻回 true
