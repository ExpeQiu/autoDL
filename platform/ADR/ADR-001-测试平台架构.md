## 背景（Context）

- 需要一个**测试平台**：提交文本 / 图片 / 视频生成任务，对照结果、记录耗时与失败。
- 算力在 AutoDL ComfyUI（实例内 `:8188`，本机经 SSH 隧道访问 `127.0.0.1:8188`）。
- cyberspaceAI 已是模板 5 画布，协议可对照，产品目标不同，不能再做一套 React Flow。

## 选项（Options Considered）

| # | 选项 | 优势 | 劣势 |
|---|------|------|------|
| A | 模板 5 再开画布 | 可复用 cyberspaceAI | 产品不是编排画布，重复建设 |
| B | 模板 1 分层数据流 + 6→1 | 任务进管道、结果可展示、算力 CLI 可拆 | 需裁剪 Uni-SIM 情报语义 |
| C | 只做模板 6 CLI | 快 | 无结果墙、无对比验收 |

## 决策（Decision）

**选 B：模板 1 + 组合 6→1。**

参考仓（只读，不 fork）：

- 管道形态：`/Volumes/Lexar/git/03T/Uni-SIM`
- ComfyUI 协议：`/Volumes/Lexar/git/03T/cyberspaceAI` 的 `lib/ai/clients/comfyui.ts`；本仓文档 `comfyui/comfyui&autodl.md`
- CLI 规范：`/Volumes/Lexar/git/15CLI/CLI标准.md`

模板 1 必答：

| # | 问题 | 决策 |
|---|------|------|
| 1 | Monorepo 多 CLI vs 多仓 | **AutoDL 仓内 `platform/` 子树**，不新开仓；CLI 升格见 **ADR-002**（`compute-cli/`，命令 `autodl`） |
| 2 | 是否双写 | **否**。真相 = SQLite 任务表 + `artifacts/`；不做 RAG |
| 3 | 编排中枢 | FastAPI `orchestrator`，默认 **`:8090`** |
| 4 | 运行时 | 本机 `scripts/start.sh`；SSH 隧道独立进程；**Docker 非默认**；AutoDL **按需开机** |
| 5 | 智能层 | 自动打分按需批处理；GPU / ComfyUI **用完即关**，禁止 24h 空转 |

Web 展示层用 **Next.js + shadcn**（Guide 05），P1 再铺；Day-0 只保证编排 `/health` + Mock 出图/文/视频任务。

## 理由（Rationale）

- 主线是「用例进入 → 路由算力 → 落结果 → 看板」，不是对话 Agent，也不是节点画布。
- AutoDL 端口每次开机会变，业务只认隧道后的本机地址，与现有 ComfyUI 文档一致。
- Mock First：`AI_MOCK_MODE=true` 先验逻辑，不依赖 GPU。

## 后果（Consequences）

### 正面

- 与 cyberspaceAI 划界清晰：画布创作 vs 生成验收。
- 关机 / 断隧道时编排可降级 Mock 或报健康失败，不写死公网 IP。

### 负面 / 风险

- 视频工作流（MiniMax H3）体积大，50GB 数据盘需扩容后才能跑真视频。
- 隧道断开后本机 `:8188` 立即失效，必须有健康探测。
