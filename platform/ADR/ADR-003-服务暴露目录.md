# ADR-003：对外服务目录（文本 / 图片 / 视频）

## 状态

| 字段 | 值 |
|------|-----|
| 状态 | Accepted |
| 决策日期 | 2026-09-19 |
| 决策者 | Architect |
| 适用范围 | `platform/orchestrator`、`platform/apps/web`、`compute-cli` |

---

## 背景（Context）

cyberspaceAI 等外部应用需要发现 AutoDL 当前对外提供哪些生成能力（文本、图片、视频），再选中并调用。隧道与开机仍走 CLI，不在此目录里。编排已有 `/v1/jobs`，但没有「哪些服务愿意被别人看见」的配置面。

## 选项（Options Considered）

| # | 选项 | 优势 | 劣势 |
|---|------|------|------|
| A | 各应用自己写死 `llm.chat` / `t2i.demo` / `t2v.u03` | 零代码 | 开关无法配置；删模型后调用方仍看到 |
| B | 编排 `services.json` + Web 页 + `autodl service list` | UI 真源；CLI 可发现；三模态统一 | 多一个文件 |
| C | 只读环境变量 / `.env` 模型列表 | 实现快 | 刷新会盖回用户关掉的暴露开关 |

## 决策（Decision）

**选 B。** 真源是 `platform/data/services.json`（gitignore）。默认三条：

| id | modality | workflow_id |
|----|----------|-------------|
| `llm.chat` | text | `llm.chat` |
| `t2i.demo` | image | `t2i.demo` |
| `t2v.u03` | video | `t2v.u03` |

规则：

- GET `/v1/services`：缺 id 才补目录默认；已写出的 `exposed=false` **不得**被默认或 `.env` 翻回 true。
- PUT 整表替换后再 hydrate；PATCH `/{id}` 改单条。
- Web `/services` 是**服务配置**页：接入（本地服务 / autodl租赁 两套路径 + Mock）+ 对外目录；测试页面状态标签链到本页。
- 接入真源 `data/access.json`。已写出的 `mock_text=false`、分套 Host、SSH 端口、文/图/视频通道 **不得**被 `.env` 翻回；切换 profile 不得抹掉另一套路径。GET 不回传 SSH 密码。编排卡定义 Mock/模型，本地与 autodl 卡只配地址与 SSH。
- CLI `autodl service list`：`--demo` 返回默认三条；live 读编排。发现后调用仍走 `job submit`。
- 调用方（cyberspaceAI）按 `items[].invoke` 提交，不要每请求 `exec autodl`。

## 理由（Rationale）

配置属于 UI/DB，不是环境变量。三模态共用同一目录，避免文本一套、图视频另一套。CLI 给 Agent 发现，HTTP 给应用调用。

## 后果（Consequences）

- 关闭暴露后，`service list --exposed` 不再列出，本机结果墙仍可提交。
- 新增工作流时在目录加 id，不要改 `.env` 默认去覆盖已保存行。
