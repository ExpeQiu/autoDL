# AutoDL 新服务器完整重新部署

把**当前 GPU 实例上的全部服务**搬到一台新 AutoDL 实例，并让两个本机仓库重新接到租赁算力。

系统设计见 [系统设计.md](./系统设计.md)。**产品与 Agent 只对接 AutoDL 或 AI-API-hub**；换机时先在 ComfyUI 仓编排租赁 ComfyUI，再由本仓接入暴露。

| 仓库 | 层 | 连租赁 GPU 的方式 |
|------|----|-------------------|
| [ComfyUI](/Volumes/Lexar/git/10%20baseTools/ComfyUI) | **能力面**（不给产品当网关） | `./start.sh autodl` |
| 本仓 AutoDL | **本地网关**：目录 + `/v1/jobs` | 隧道 8188+8088 + `:8090` |
| [AI-API-hub](/Volumes/Lexar/git/10%20baseTools/AI-API-hub) | **云端网关**：商业 API | 与本机 GPU 无关，`:8055` |

ComfyUI **默认走租赁卡**（`COMFYUI_TARGET=autodl`）。本机 `./start.sh local` 只作断卡 fallback，不要当对外生产路径。

登录口令与动态 SSH 端口只写在 `guide/服务器&ssh.md`（以控制台为准）。对照：`comfyui/comfyui&autodl.md`、`model/llm&autodl.md`、ComfyUI 仓 `QUICKSTART.md`。

## 2. 两仓契约（换机后必须对齐）

### 2.1 SSH 真源

ComfyUI `scripts/env.sh` **会再加载** AutoDL `platform/.env`。换机改端口时：

1. 先改 AutoDL `platform/.env` 的 `COMFYUI_SSH_HOST/PORT/USER/PASSWORD`
2. ComfyUI 根 `.env` 可只留 `COMFYUI_TARGET=autodl` 等；端口空着会吃 platform 的值
3. 若 ComfyUI `.env` 自己写了端口，以**后加载的 platform/.env 为准**（`env.sh` 顺序：ComfyUI `.env` → `CLi/.env` → `platform/.env`）

密码不要提交。本机用 `sshpass` 或密钥。

### 2.2 业务永远打隧道后的本机地址

禁止写 AutoDL 公网 IP。ComfyUI / `comfyctl` / cyberspaceAI / 测试平台一律：

```text
http://127.0.0.1:8188          # 只跑租赁一套时
# 或
http://comfy.autodl:8189       # 本机 ComfyUI 与租赁同时在线时
```

对应变量：`COMFYUI_AUTODL_ENDPOINT`（ComfyUI 仓）、`COMFYUI_ENDPOINT`（AutoDL platform）。

### 2.3 `:8188` 同一时刻只能有一个主人

| 场景 | 做法 |
|------|------|
| 只用租赁（推荐） | 停本机 ComfyUI；隧道绑 8188；`./start.sh autodl` |
| 本机 + 租赁同时 | `/etc/hosts` 加 `comfy.local` / `comfy.autodl`；本机 `COMFYUI_PORT=8188`，隧道 `COMFYUI_TUNNEL_PORT=8189` |
| 测试平台还要 llama | AutoDL `tunnel.sh` 额外转 8088；**不要**与 ComfyUI `tunnel.sh` 抢同一个 8188 |

ComfyUI `./stop.sh autodl` **默认只停本机隧道**，不停租赁上的 ComfyUI。要关远端：`STOP_REMOTE_COMFYUI=1 ./stop.sh autodl`。

实际连哪套以 `ComfyUI/logs/active-target` 为准（`local` 或 `autodl`），不是只看 `COMFYUI_TARGET`。

## 12. 故障速查

| 现象 | 处理 |
|------|------|
| SSH 连不上 | 控制台是否开机；端口是否已变；改 `platform/.env` 与 `服务器&ssh.md` |
| `./start.sh autodl` 后变成 local | 关 fallback：`COMFYUI_START_MODE=autodl` `COMFYUI_FALLBACK_LOCAL=0`；查 `logs/start.log` |
| 本机 8188 通、实例不通 | 本机 ComfyUI 占了端口；`./stop.sh local` 或隧道改 8189 |
| 两仓隧道冲突 | 只留 ComfyUI 或 platform 其中一个转 8188 |
| `verify.sh autodl` 失败 | 先 `remote.sh status`，再看 `tunnel.log` |
| 画布无运维栏 | `deploy-autodl-ecosystem.sh` 或 `OPS/scripts/deploy.sh` 后远端重启 |
| 工作流缺节点 | 再部署生态；H3 官方节点随 0.33，不要装 MiniMaxH3-Cache |
| torch 变 CPU | 重跑 `comfyui_install.sh` 的 cu128 钉装 |
| 磁盘满 | 勿下 bf16；清 huggingface cache；H3 用 wget 直写 `models/` |
| OOM | H3 与 llama 是否同时驻留 |
| 保存的 Host 刷新变回去 | UI/DB 优先，禁止启动覆盖；见 `ui-config-not-env-overwrite` |

排查序：SSH 端口 → 实例内 `/system_stats` → 本机隧道与端口占用 → `active-target` → 各仓日志。
