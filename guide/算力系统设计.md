# 系统设计：能力编排 × 双网关接入

**产品应用不直连 GPU、不直连厂商 Key。** cyberspaceAI 与其他 Agent 平台只对接两个网关拿 AI 能力：


| 网关          | 仓库                                                         | 拿什么                                    |
| ----------- | ---------------------------------------------------------- | -------------------------------------- |
| **云端**      | [AI-API-hub](/Volumes/Lexar/git/10%20baseTools/AI-API-hub) | 多厂商商业 API（对话 / 生图 / 视频），OpenAI 兼容      |
| **本地 / 租赁** | 本仓 AutoDL                                                  | 本机或 AutoDL 卡上的 ComfyUI + llama，按服务目录暴露 |


两者并列，由调用方选通道（Gspace：云端服务 Tab vs 本地服务 Tab）。ComfyUI 仓在 AutoDL **后面**，只编排租赁卡上的工作流，不给产品当 HTTP 入口。

换机步骤见 [新服务器重新部署.md](./新服务器重新部署.md)。Hub 对接见 AI-API-hub `guide/INTEGRATION.md`。

## 1. 总图

```text
cyberspaceAI / 其他 Agent 平台
        │
        ├── 云端  AI_GATEWAY_BASE_URL + Key
        │         /v1/chat/completions
        │         /v1/images/generations
        │         /v1/video/generations
        │                    ▼
        │         ┌─────────────────────┐
        │         │ AI-API-hub  :8055   │  鉴权 · 配额 · 路由
        │         └──────────┬──────────┘
        │                    ▼
        │         MiniMax / CloseAI / 企业 Gateway / …
        │
        └── 本地  AUTODL_ORCH_BASE
                  GET /v1/services    POST /v1/jobs
                  或 autodl service list / job submit
                             ▼
                  ┌─────────────────────┐
                  │ AutoDL 接入面 :8090 │  本仓
                  └──────────┬──────────┘
                             │ 隧道后 :8188 / :8088
                             ▼
                  ┌─────────────────────┐
                  │ ComfyUI 能力面      │  ComfyUI 仓
                  └──────────┬──────────┘
                             │ SSH
                             ▼
                  租赁实例 ComfyUI :8188  +  llama :8088
```


| 层              | 仓库                            | 做                           | 不做                                 |
| -------------- | ----------------------------- | --------------------------- | ---------------------------------- |
| **产品 / Agent** | cyberspaceAI、Hermes、OpenClaw… | 选云端或本地通道，提交文/图/视频           | 不存 SSH 密码、厂商 Key、节点 ID             |
| **云端网关**       | AI-API-hub                    | 统一 `/v1/`*，Key 与配额在服务端      | 不调度 AutoDL 实例、不打 ComfyUI `/prompt` |
| **本地网关**       | AutoDL                        | 开关机、隧道、服务目录、`/v1/jobs`      | 不复刻画布；不代理商业云 API                   |
| **能力面**        | ComfyUI                       | 编排租赁 ComfyUI 的节点 / 工作流 / 画布 | 不给 Gspace 当网关                      |
| **执行面**        | 租赁 GPU / 厂商 API               | 真正推理                        | 不暴露公网 IP 给产品                       |

## 2. 调用方：只认两个入口


| 通道  | Base                              | 鉴权                                    | 发现                              | 调用                                   |
| --- | --------------------------------- | ------------------------------------- | ------------------------------- | ------------------------------------ |
| 云端  | `AI_GATEWAY_BASE_URL`（生产 `:8055`） | `Authorization: Bearer sk-transtai-…` | `GET /v1/models`                | OpenAI 兼容 chat / images / video      |
| 本地  | `AUTODL_ORCH_BASE`（`:8090`）       | 本机信任（不把 SSH 给调用方）                     | `GET /v1/services?exposed=true` | `POST /v1/jobs` 再轮询；Agent 用 `autodl` |


cyberspaceAI：

- 云端服务 → `lib/ai/clients/ai-api-hub.ts`（及企业 Gateway）
- 本地服务 → AutoDL `/v1/services` 勾选后写入本地服务商（`guide/本地服务模式.md`）
- **禁止**新产品再抄 `ComfyUIClient` 直打 `:8188`；历史直连仅作降级

Agent 平台同理：云端走 hub HTTP（或 `transtai` CLI）；本地走 `autodl service list` / `job submit`，不要每请求 `exec autodl` 当 SDK。

两通道可同时开：云端保底、本地有卡时走租赁。路由在调用方（Gspace 节点选服务商），不在 ComfyUI 仓。

## 3. 云端网关：AI-API-hub

把 MiniMax、CloseAI、企业 ToB Gateway、Seedance 等收成一个 Host。调用方只配 Base + 平台 Key，厂商 Key 留在 hub 的 UI/DB（禁止被 `.env` 盖回已保存行）。


| 场景   | 路径                            | 典型 model                           |
| ---- | ----------------------------- | ---------------------------------- |
| 对话   | `POST /v1/chat/completions`   | `MiniMax-M3` / `deepseek-chat`     |
| 生图   | `POST /v1/images/generations` | `image-01` / `gpt-image-1`         |
| 视频   | `POST /v1/video/generations`  | `MiniMax-H3`（云端 API，不是租赁卡上的 H3 权重） |
| 企业视频 | `/aigc/.../tasks`             | Seedance                           |


同一「MiniMax-H3」名字：云端是 **Hailuo HTTP API**；本地是 **ComfyUI 开源权重**。产品里要用服务商区分，不要混成一个 endpoint。

## 4. 本地网关：AutoDL 接入面

外仓只看见「有哪些服务、怎么提交」，看不见 SSH 和节点图。

### 4.1 接入（算力接到本机）

- 实例：`autodl instance power-on/off`
- 隧道：`127.0.0.1:8188` → ComfyUI；`:8088` → llama
- 健康：`GET /v1/compute/health`
- 真源：`data/access.json`（`profile=local|autodl`）。已保存 Host/Mock **不被 .env 盖回**

SSH 只写在 `guide/服务器&ssh.md` 与本机 `.env`。ComfyUI `scripts/env.sh` 读取 `platform/.env`。

### 4.2 暴露

真源 `data/services.json`：


| id         | 模态    | 背后                         |
| ---------- | ----- | -------------------------- |
| `llm.chat` | text  | llama.cpp `:8088`          |
| `t2i.demo` | image | 本卡无 Flux，默认 Mock           |
| `t2v.u03`  | video | 租赁 ComfyUI MiniMax H3 开源权重 |


`exposed=false` 后 `?exposed=true` 不再列出；本机结果墙仍可测。

测试平台 `:3190` 是接入面的第一调用方（打分、耗时），不是第二套画布。

## 5. 能力面：ComfyUI 仓（只服务 AutoDL 后面）

目标：租赁卡上的 ComfyUI 与本机技能库一致。入口 `./start.sh autodl`。


| 编排对象 | 真源                            | 落到租赁                                |
| ---- | ----------------------------- | ----------------------------------- |
| 运行时  | AutoDL `scripts/comfyui_*.sh` | `/root/autodl-tmp/ComfyUI` `:8188`  |
| 节点   | `githublab/` + `OPS/`         | `custom_nodes/`                     |
| 技能   | `Source/workflows/`           | `/root/autodl-tmp/Source/workflows` |
| 侧边栏  | `comfyui工作流仓库/` → `Source/user-workflows/` | `user/default/workflows/`           |
| 权重   | 不进 Source                     | `models/`（`comfyui_download_h3.sh`） |


`./start.sh local` 只是断卡 fallback，不是产品生产路径。`:8190` 是 ComfyUI 运维控制面，调用方是人 / `comfyctl`，不是 Gspace。

接入面内部 adapter 仍打 `/prompt`（`platform/orchestrator/app/adapters/comfyui.py`）。画布播放模式、H3 节点和工作流同步见 [生成链路.md](./生成链路.md)。改节点先改 ComfyUI 仓，再改 `platform/workflows/` 与 `services.json` 的 id。

5090 上 H3 与 llama 不能同时驻留；由接入面通道开关约束。

## 7. 反模式

- 产品仓写 AutoDL 公网 IP、动态 SSH、ComfyUI 节点 ID
- 产品仓直连 MiniMax / OpenAI（应走 hub，Key 在 hub）
- 产品仓直连租赁 `:8188` 当「本地服务」（应走 AutoDL `:8090`）
- ComfyUI 仓再做 `/v1/jobs` 给 Gspace
- AutoDL 仓再代理商业云 API（那是 hub）
- AutoDL 仓再做 React Flow 画布（那是 Gspace / ComfyUI 画布）
- 把云端 `MiniMax-H3` API 与本地 H3 权重当成同一个 Host
- `exposed=false` 或 hub 里删掉的模型被 `.env` 盖回
- `./start.sh auto` fallback 到本机后仍当租赁服务对外暴露
